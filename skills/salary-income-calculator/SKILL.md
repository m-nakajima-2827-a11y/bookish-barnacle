# 給与所得 金額計算スキル（所得金額計算アプリ）

給与の収入金額（Ａ）を入力すると、給与所得の金額を自動で計算するアプリを作るためのスキルです。
計算ロジック・入力と出力の仕様・画面仕様・端数処理・テストケースを1つにまとめています。実装言語を問わず、このファイルの仕様どおりに作れば同じ結果になります。

> **前提（事実）**: 計算表はユーザー提供の早見表（下記「2. 計算ロジック」）をそのまま採用しています。
> **対象年分（確定）**: この早見表は **2026年（令和8年）分** の給与所得に適用します（発注者確認済み）。`TABLE_VERSION` に記録し、画面にも対象年分を表示します。2025年分以前の計算には使えません。
> **参照ページ**: https://tax.mykomon.com/tool-nen2020.html の仕様を踏襲します。作成時点ではこの環境から参照ページを閲覧できなかったため、画面の細部（項目名・ボタン名）は実画面と照合して調整してください。

## 1. アプリの目的と対象範囲

| 項目 | 内容 |
|---|---|
| 目的 | 給与の収入金額から給与所得の金額を、表どおりの端数処理で正確に計算する |
| 想定利用者 | 個人（会社員・パート）、営業担当者、経理・労務担当者、税理士事務所の職員 |
| 対象年分 | 2026年（令和8年）分 |
| 計算対象 | 給与所得の金額（所得金額調整控除・特定支出控除の適用前／適用後） |
| 対象外 | 給与以外の所得（事業・不動産・退職など）、所得税額・住民税額の計算、源泉徴収税額の計算 |
| 位置づけ | 概算ツール。結果は申告書の記載の代わりにならない旨を画面に表示する |

## 2. 計算ロジック

### 2-1. 給与所得の金額（所得金額調整控除・特定支出控除の適用前）【2026年（令和8年）分】

Ａ ＝ 給与の収入金額（円・整数）

| No | 給与の収入金額（Ａ） | 所得金額 |
|---|---|---|
| 1 | 1円以上 740,999円以下 | 0円 |
| 2 | 741,000円以上 2,190,999円以下 | Ａ − 740,000円 |
| 3 | 2,191,000円以上 2,192,999円以下 | 1,451,000円（固定） |
| 4 | 2,193,000円以上 2,195,999円以下 | 1,453,000円（固定） |
| 5 | 2,196,000円以上 2,199,999円以下 | 1,456,000円（固定） |
| 6 | 2,200,000円以上 3,599,999円以下 | Ｂ × 2.8 − 80,000円 |
| 7 | 3,600,000円以上 6,599,999円以下 | Ｂ × 3.2 − 440,000円 |
| 8 | 6,600,000円以上 8,499,999円以下 | Ａ × 0.9 − 1,100,000円 |
| 9 | 8,500,000円以上 | Ａ − 1,950,000円 |

- **Ｂ ＝ Ａ ÷ 4（千円未満切捨て）**。No.6・No.7だけで使います。
  - 例: Ａ＝3,001,999円 → 3,001,999 ÷ 4 ＝ 750,499.75 → Ｂ＝750,000円
- Ａが0円（または未入力）のときは計算しません（入力エラー）。
- No.3〜5は「表で決まる固定額」です。計算式に置き換えないでください。

### 2-2. 所得金額調整控除

対象者に当てはまる場合のみ、2-1の金額から差し引きます。①と②の両方に当てはまる場合は合計額を差し引きます。

**① 子育て・介護世帯（給与の収入金額が850万円超）**

```
控除額① ＝（給与の収入金額〔上限 10,000,000円〕− 8,500,000円）× 10%
```

- 適用条件（いずれか1つに当てはまること）
  - 本人が特別障害者である
  - 23歳未満の扶養親族がいる
  - 特別障害者である同一生計配偶者または扶養親族がいる
- 給与の収入金額が850万円以下なら0円。上限は150,000円。
- 1円未満の端数は**切上げ**（法令上の取扱い。実装時に国税庁資料で再確認）。

**② 給与所得と公的年金等の雑所得の両方がある場合**

```
控除額② ＝ 給与所得控除後の給与等の金額〔上限 100,000円〕
          ＋ 公的年金等に係る雑所得の金額〔上限 100,000円〕− 100,000円
```

- 「給与所得控除後の給与等の金額」は2-1の結果を使います。
- 結果がマイナスなら0円。上限は100,000円。

### 2-3. 特定支出控除

利用者が入力した「特定支出控除の額」（別途計算済みの金額）を差し引きます。アプリ内では特定支出の判定・計算は行いません（入力値として受け取る）。

### 2-4. 最終的な所得金額

```
給与所得の金額 ＝ max(0, 2-1の金額 − 控除額① − 控除額② − 特定支出控除の額)
```

### 2-5. 参考表示：給与所得控除額

```
給与所得控除額（相当額）＝ Ａ − 2-1の金額
```

※ 表で計算するため、控除額は「表から逆算した相当額」です。画面ではその旨を注記します。

## 3. 参考実装（Python）

```python
import math

TABLE_VERSION = "2026年（令和8年）分"

def salary_income_before_adjustment(a: int) -> int:
    """給与所得の金額（所得金額調整控除・特定支出控除の適用前）"""
    if a < 1:
        raise ValueError("給与の収入金額は1円以上で入力してください")
    if a <= 740_999:
        return 0
    if a <= 2_190_999:
        return a - 740_000
    if a <= 2_192_999:
        return 1_451_000
    if a <= 2_195_999:
        return 1_453_000
    if a <= 2_199_999:
        return 1_456_000
    if a <= 6_599_999:
        b = (a // 4) // 1000 * 1000          # A÷4（千円未満切捨て）
        if a <= 3_599_999:
            return b * 28 // 10 - 80_000     # B×2.8−80,000
        return b * 32 // 10 - 440_000        # B×3.2−440,000
    if a <= 8_499_999:
        return a * 9 // 10 - 1_100_000       # A×0.9−1,100,000
    return a - 1_950_000

def adjustment_1(a: int, eligible: bool) -> int:
    """所得金額調整控除①（子育て・介護）"""
    if not eligible or a <= 8_500_000:
        return 0
    return math.ceil((min(a, 10_000_000) - 8_500_000) * 10 / 100)

def adjustment_2(salary_income: int, pension_income: int) -> int:
    """所得金額調整控除②（給与と年金の両方）"""
    if salary_income <= 0 or pension_income <= 0:
        return 0
    return max(0, min(salary_income, 100_000) + min(pension_income, 100_000) - 100_000)

def calculate(a: int, eligible_1: bool = False, pension_income: int = 0,
              specific_expense: int = 0) -> dict:
    base = salary_income_before_adjustment(a)
    adj1 = adjustment_1(a, eligible_1)
    adj2 = adjustment_2(base, pension_income)
    final = max(0, base - adj1 - adj2 - specific_expense)
    return {
        "給与の収入金額": a,
        "給与所得控除額（相当額）": a - base,
        "給与所得の金額（調整前）": base,
        "所得金額調整控除①": adj1,
        "所得金額調整控除②": adj2,
        "特定支出控除": specific_expense,
        "給与所得の金額": final,
        "計算表バージョン": TABLE_VERSION,
    }
```

実装上の注意:
- **浮動小数点を使わない**。`×2.8` は `×28÷10`、`×0.9` は `×9÷10` のように整数演算にします（Ｂは千円単位、Ａは整数のため割り切れます）。
- JavaScriptで作る場合も `Math.floor` と整数演算で同じ結果になるようにし、下記テストケースで確認します。

## 4. 入力・出力仕様

### 4-1. 入力項目

| No | 項目名 | 型 | 単位 | 必須 | 初期値 | 制約・備考 |
|---|---|---|---|---|---|---|
| 1 | 給与の収入金額（Ａ） | 整数 | 円 | 必須 | 空欄 | 1〜999,999,999。カンマ入力・全角数字を許容し、半角整数に変換 |
| 2 | 所得金額調整控除①の対象 | チェックボックス | − | 任意 | オフ | 本人特別障害者／23歳未満の扶養親族あり／特別障害者の同一生計配偶者・扶養親族あり。Ａが850万円超のときだけ有効化 |
| 3 | 公的年金等に係る雑所得の金額 | 整数 | 円 | 任意 | 0 | 0以上。入力があるときだけ控除②を計算 |
| 4 | 特定支出控除の額 | 整数 | 円 | 任意 | 0 | 0以上。アプリでは計算せず入力値をそのまま使用 |

### 4-2. 出力項目

| No | 項目名 | 単位 | 備考 |
|---|---|---|---|
| 1 | 給与所得控除額（相当額） | 円 | Ａ − 調整前の所得金額 |
| 2 | 給与所得の金額（調整前） | 円 | 2-1の結果 |
| 3 | 所得金額調整控除① | 円 | 対象外は0円 |
| 4 | 所得金額調整控除② | 円 | 対象外は0円 |
| 5 | 特定支出控除 | 円 | 入力値 |
| 6 | **給与所得の金額** | 円 | 最終結果。最も大きく表示 |
| 7 | 適用した計算区分 | − | 例「No.6：Ｂ×2.8−80,000円（Ｂ＝750,000円）」 |

金額は3桁カンマ区切りで表示します（例: 2,020,000円）。

## 5. 画面仕様（参照ページを踏襲）

縦1列の、入力 → 計算 → 結果のシンプルな構成にします。

1. **タイトル**: 「給与所得の計算（2026年（令和8年）分）」
2. **入力欄**: 給与の収入金額（円）
3. **オプション（折りたたみ）**: 所得金額調整控除①の対象／公的年金等の雑所得／特定支出控除
4. **ボタン**: 「計算する」「クリア」
5. **結果欄**: 4-2の出力項目（最終結果を強調）
6. **計算表**: 2-1の早見表を掲載し、該当した行をハイライト
7. **注意書き**（固定表示・原文どおり）:
   - 「※所得金額調整控除や特定支出控除適用前の金額です。特に年収850万円超の方はご注意ください。」
   - 「（※）所得金額調整控除又は特定支出控除の適用がある場合には、上記所得金額からそれぞれの控除額を控除してください。」
   - 「本ツールの計算結果は概算です。実際の申告・年末調整では最新の法令・国税庁の資料をご確認ください。」

動作:
- 「計算する」押下で計算。入力中の自動計算は任意（実装する場合は入力確定時）。
- 「クリア」で全項目を初期値に戻し、結果欄を非表示にします。
- スマートフォン幅（375px）で横スクロールが出ないこと。数値入力は `inputmode="numeric"`。

## 9. このスキルの使い方（Claudeへの指示）

1. 依頼が「計算アプリを作る」なら、2〜6の仕様どおりに実装し、7のテストケースをすべて自動テストにします。
2. 依頼が「この年収の所得を計算して」なら、3の参考実装どおりに計算し、適用区分と計算過程（Ｂの値を含む）を示して回答します。
3. この計算表は2026年（令和8年）分専用です。2025年分以前や2027年分以降の計算を求められたときは、この表を流用せず、その年分の計算表を利用者に確認します。根拠のない改正内容や数値を補わないでください。
4. 結果には「概算であり、実際の申告では最新の法令・国税庁の資料を確認すること」を必ず添えます。
