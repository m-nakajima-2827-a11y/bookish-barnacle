# ワークブック仕様

`scripts/build_workbook.py` が生成する収支管理ブックの全仕様です。シートの追加・列の変更をするときは、このファイルとスクリプトを両方更新してください。

## 全体設計

```
[マスタ]                         [日々の入力]                [集計・分析]
材料マスタ ─▶ レシピ ─▶ 商品マスタ ─▶ 売上入力 ───────┐
費目マスタ ───────────────────────▶ 経費入力 ───────┼─▶ 月次損益（チャネル別）
設備（減価償却） ──────────────────────────────────┤   年間推移（12か月）
                                 棚卸（月末） ───────┘   シミュレーション（試算）
設定（年度・表示月・税率・配賦方法・目標）──▶ 全シート
```

- 損益はすべて **税抜** で集計します（売上・経費は税込で入力し、税率で自動換算）。
- 集計は **日付の範囲 × チャネル × 費目区分** の SUMIFS が基本です。年月の補助列は使いません。
- 色の約束：**黄色＝入力**、灰色＝計算式、緑＝合計・重要指標、オレンジ＝警告（条件付き書式）。

## シート別仕様

### 1. 使い方
入力手順・凡例・注意事項。`--sample` 時は「架空データ」の警告行が先頭に入ります。

### 2. 設定

| セル | 項目 | 既定値 | 用途 |
|---|---|---|---|
| B3 | 店舗名 | （店舗名） | 表示用 |
| B4 | 事業年度の開始日 | `--fy-start` | 年間推移の1か月目 |
| B5 | 月次損益で表示する月 | 事業年度開始日 | 月次損益の対象月（1日を入力） |
| B6 | 標準税率 | 10% | イートイン売上 |
| B7 | 軽減税率 | 8% | 持ち帰り売上、商品マスタの税抜価格 |
| B8 | 共通費の配賦方法 | 売上比 | 売上比／手入力 |
| B9 | 目標営業利益（月） | 0 | 必要販売数の計算 |
| B10 | 目標原価率（目安） | 30% | 商品マスタの判定・シミュレーションの警告色。自店方針で変更 |
| A13:A15 | チャネル名 | 店舗／キッチンカー／自販機 | 全シートの見出し・プルダウン |
| B13:B15 | 手入力時の配賦率 | 50%／30%／20%（仮） | B8＝手入力のときだけ使用 |
| A16 | 共通 | 固定 | 経費・設備専用のチャネル |

### 3. 材料マスタ（4〜203行）

| 列 | 項目 | 種別 | 計算式・備考 |
|---|---|---|---|
| A | 材料名 | 入力 | レシピのプルダウン元 |
| B | 区分 | 入力 | 食材／包材／その他 |
| C | 仕入先 | 入力 | |
| D | 購入価格（税抜） | 入力 | |
| E | 購入量 | 入力 | |
| F | 単位 | 入力 | g／ml／個／枚／本／袋 |
| G | 歩留まり率 | 入力 | 空欄＝100%。皮・ヘタ・ロスを除いた使用可能割合 |
| H | 使用単価 | 計算 | `=D/(E×歩留まり)` |

### 4. レシピ（4〜603行）
1行＝1商品×1材料。生地の材料も各商品に登録します。

| 列 | 項目 | 計算式 |
|---|---|---|
| A | 商品名 | 入力（商品マスタのプルダウン） |
| B | 材料名 | 入力（材料マスタのプルダウン） |
| C | 使用量 | 入力（材料マスタの単位で） |
| D | 単位 | `VLOOKUP(材料名, 材料マスタ, 6)`。未登録なら「未登録」＋警告色 |
| E | 使用単価 | `VLOOKUP(材料名, 材料マスタ, 8)` |
| F | 材料原価 | `=C×E` |

### 5. 商品マスタ（4〜103行）

| 列 | 項目 | 計算式 |
|---|---|---|
| A | 商品名 | 入力 |
| B | カテゴリ | 入力 |
| C | 販売価格（税込） | 入力 |
| D | 材料原価 | `SUMIF(レシピ!A, 商品名, レシピ!F)` |
| E | 税抜価格（持ち帰り） | `=C/(1+軽減税率)` |
| F | 原価率 | `=D/E` |
| G | 粗利（円/個） | `=E−D` |
| H | 判定 | レシピ未登録／要見直し（原価率＞目標）／OK |

### 6. 費目マスタ（4〜43行）

| 列 | 項目 | 備考 |
|---|---|---|
| A | 費目 | 経費入力のプルダウン元 |
| B | P&L区分 | 売上原価／変動費／固定費（損益のどこに入るかを決める） |
| C | 既定税率 | 経費入力で税率が空欄のときに使用 |
| D | 説明・例 | |

既定の費目と区分は `cost-calculation-guide.md` の「費目とチャネルの振り分け」を参照。**減価償却費は設備シートから自動計上するので費目に入れません。**

### 7. 設備（4〜53行）

| 列 | 項目 | 計算式 |
|---|---|---|
| A | 設備名 | 入力 |
| B | チャネル | 入力（共通を含む） |
| C | 取得日 | 入力 |
| D | 取得価額（税抜） | 入力 |
| E | 耐用年数 | 入力 |
| F | 月額償却費 | `=ROUND(D/(E×12),0)`（定額法・残存価額なしの簡易計算） |
| G | 償却終了日 | `=EDATE(C, E×12)−1` |

月次損益には「取得日 ≦ 月末 かつ 償却終了日 ≧ 月初」の設備の F を計上します。

### 8. 売上入力（4〜3003行）
1行＝日付×チャネル×商品（×販売区分）。

| 列 | 項目 | 計算式 |
|---|---|---|
| A〜D | 日付／チャネル／販売区分／商品名 | 入力 |
| E | 販売数 | 入力 |
| F | 廃棄数 | 入力（自販機の期限切れ回収、作り置きロスなど） |
| G | 値引額（税込） | 入力 |
| H | 単価上書き（税込） | 入力（イベント価格・セット価格など） |
| I | 適用単価 | H があれば H、なければ商品マスタの販売価格 |
| J | 売上（税込） | `=E×I−G` |
| K | 税率 | イートイン＝標準税率、それ以外＝軽減税率 |
| L | 売上（税抜） | `=ROUND(J/(1+K),0)` |
| M | 材料原価（理論） | `=E×商品マスタの材料原価` |
| N | 廃棄原価 | `=F×商品マスタの材料原価` |

### 9. 経費入力（4〜2003行）

| 列 | 項目 | 計算式 |
|---|---|---|
| A〜E | 日付／費目／チャネル／支払先／摘要 | 入力 |
| F | 金額（税込） | 入力 |
| G | 税率 | 入力（空欄＝費目マスタの既定税率） |
| H | 金額（税抜） | `=ROUND(F/(1+税率),0)` |
| I | P&L区分 | `VLOOKUP(費目, 費目マスタ, 2)`。未登録なら警告色 |

### 10. 棚卸（4〜203行）
月末日・チャネル・在庫金額（税抜）。同じ月内の日付ならどの日でもその月の月末在庫として扱います。開業時（期首）在庫は前月末の日付で入力します。

### 11. 月次損益

列：店舗／キッチンカー／自販機／共通／合計。対象月は 設定!B5。

| ブロック | 行 | 計算 |
|---|---|---|
| 売上 | 売上高（税抜）、販売数、廃棄数、1個あたり売上 | 売上入力を SUMIFS |
| 売上原価 | 期首在庫、材料・包材仕入、期末在庫、売上原価、粗利、粗利率 | 売上原価＝前月末棚卸＋当月仕入（区分＝売上原価）−当月末棚卸 |
| 変動費 | 費目別明細、変動費計、限界利益 | 変動費計は区分＝変動費の SUMIFS（明細にない新費目も含む） |
| 固定費 | 費目別明細、減価償却費、固定費計、チャネル貢献利益 | 固定費計＝区分＝固定費の SUMIFS＋減価償却費 |
| 共通費の配賦 | 配賦率、共通費配賦額、営業利益、営業利益率 | 配賦額＝共通列の貢献利益（マイナス）×配賦率。合計列は0 |
| KPI | 原価率（実際・理論）、原価差異、廃棄原価、人件費率、FL比率、損益分岐点売上・販売数、安全余裕率、目標達成に必要な販売数 | 定義は `cost-calculation-guide.md` |
| 入力チェック | 経費入力の当月合計 − 損益計上額 | 0以外＝費目・チャネルの未登録／空欄がある |

### 12. 年間推移
事業年度開始日から12か月。列：チャネル別売上、売上合計、販売数、売上原価、粗利、粗利率、変動費、固定費（償却含む）、営業利益、営業利益率、原価率、累計営業利益。年間合計行と「チャネル別売上（積み上げ棒）＋営業利益（折れ線）」のグラフ付き。棚卸未入力の月は仕入額＝売上原価になります。

### 13. シミュレーション（実績とは非連動の試算用）
- ① 販売価格（650/700/750/800円・税込）× 材料原価 → 原価率の早見表。目標原価率超えは警告色。価格・原価の値は黄色セルで変更可。
- ② チャネル別の月間損益試算：平均単価、1日販売数、営業日数、1個原価、変動費率、月間固定費 → 売上・限界利益・営業利益・損益分岐点販売数（月・日）。

## 検証

生成・改修後は必ず再計算してエラーがないことを確認します。

```bash
python scripts/build_workbook.py --out /tmp/x.xlsx --sample --fy-start 2027-04-01
soffice --headless --calc --convert-to xlsx --outdir /tmp/recalc /tmp/x.xlsx
python - <<'EOF'
from openpyxl import load_workbook
wb = load_workbook("/tmp/recalc/x.xlsx", data_only=True)
for ws in wb:
    errs = [c.coordinate for row in ws.iter_rows() for c in row
            if isinstance(c.value, str) and c.value.startswith(("#", "Err:"))]
    print(ws.title, "OK" if not errs else errs[:10])
print("入力チェック:", wb["月次損益"]["F61"].value)  # 0 なら正常（行番号は費目数で変わる）
EOF
```

確認ポイント：
- 全シートにエラー値がない
- 月次損益の「入力チェック」が 0
- 月次損益の合計列の営業利益 ＝ 年間推移の同月の営業利益
- 共通費配賦額の合計列が 0

## カスタマイズ

| やりたいこと | 方法 |
|---|---|
| チャネル名を変える | 設定シート A13:A15 を変更（入力済みデータのチャネル名も置換） |
| チャネルを増やす（2号店など） | スクリプトの `CHANNELS` に追加し、`SET_CH_ROW0` 以降の行・月次損益の列・年間推移の列を拡張して再生成 |
| 費目を追加 | 費目マスタの空欄行に追加（区分を必ず選ぶ）。区分の合計には自動で入り、明細行に出したい場合はスクリプトの `EXPENSE_ITEMS` に追加して再生成 |
| 入力行数を増やす | スクリプト冒頭の `N_SALES` などを変更して再生成 |
| チャネル別に価格が違う | 売上入力の「単価上書き」を使うか、商品マスタにチャネル別の商品名（例：「いちご生クリーム（KC）」）を登録 |
