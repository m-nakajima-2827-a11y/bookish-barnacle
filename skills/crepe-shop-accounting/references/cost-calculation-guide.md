# 原価計算・収支管理ガイド

ユーザーへの説明、会話内での計算、レポートの原因分析で使う考え方をまとめています。

## 1. 原価の3層構造

| 層 | 中身 | ブック上の場所 | 見る指標 |
|---|---|---|---|
| ① 材料原価（売上原価） | 生地・クリーム・果物・具材・包材 | 材料マスタ→レシピ→商品マスタ／経費入力（売上原価）＋棚卸 | 原価率、原価差異 |
| ② 変動費 | 売上や出店回数に比例して増える経費 | 経費入力（変動費） | 限界利益率 |
| ③ 固定費 | 売上がゼロでもかかる経費 | 経費入力（固定費）＋設備（減価償却） | 損益分岐点、安全余裕率 |

### 1個あたり材料原価の計算

```
使用単価     ＝ 購入価格(税抜) ÷ (購入量 × 歩留まり率)
材料ごとの原価 ＝ 使用量 × 使用単価
1個の材料原価 ＝ Σ 材料ごとの原価（生地＋具材＋包材）
原価率       ＝ 1個の材料原価 ÷ 税抜販売価格
```

- 税抜販売価格は、持ち帰りなら 税込価格 ÷ 1.08、イートインなら ÷ 1.10。
- 生地は1回分の仕込み量（例：薄力粉1kgで何枚焼けるか）から1枚あたりの使用量に割り戻して登録します。
- 包材（包み紙・自販機用容器・ラベル）も材料原価に含めます。自販機は容器代が加わるため、同じ中身でも原価率が上がりやすい点に注意します。

### 会話内で原価率を聞かれたとき
ユーザーが原価を示した場合は、650・700・750・800円（税込）それぞれの原価率を表で返し、ブックの「シミュレーション①」にも同じ早見表があることを伝えます。原価が示されていない場合は、原価の数値を推測せず、材料の購入価格と使用量を教えてもらうか、ブックへの入力を案内します。

### 判断に迷うときのルール
1. **そのチャネルをやめたら消える経費か？** → 消えるならそのチャネル、消えないなら「共通」。
2. 店舗の厨房で仕込んだ材料をキッチンカーや自販機に回す場合は、仕入れを店舗で計上し、月末棚卸もしくは「理論原価」を参考に、月1回まとめて振替入力（店舗にマイナス、他チャネルにプラス）してもよい。
3. 光熱費は厳密には一部が変動費ですが、管理を簡単にするため固定費として扱います。

## 3. 共通費の配賦

- 「共通」に入れた経費（本部的な経費）は、月次損益で各チャネルに配賦してから営業利益を出します。
- 配賦方法は設定シートで選びます。
  - **売上比**（既定）：売上の大きいチャネルほど多く負担。
  - **手入力**：作業時間の割合などで決めた比率を使う。
- **撤退判断の注意**：判断は「チャネル貢献利益（配賦前）」で行います。配賦後が赤字でも貢献利益が黒字なら、そのチャネルは共通費の回収に貢献しているため、やめると全社の利益は減ります。

## 4. KPIの定義

| KPI | 計算式 | 読み方 |
|---|---|---|
| 原価率（実際） | 売上原価 ÷ 売上高 | 実際に消えた材料の割合 |
| 原価率（理論） | Σ（販売数 × レシピ原価）÷ 売上高 | レシピどおりなら何%か |
| 原価差異 | 実際売上原価 − 理論原価 | プラスが大きい＝ロス・盛りすぎ・記録漏れ・値上がり |
| 廃棄原価 | Σ（廃棄数 × レシピ原価） | 自販機の期限切れ、作り置きロス |
| 人件費率 | 人件費 ÷ 売上高 | |
| FL比率 | （売上原価 ＋ 人件費）÷ 売上高 | 飲食業でよく使われる効率指標 |
| 限界利益 | 売上 − 売上原価 − 変動費 | 固定費を回収する原資 |
| 損益分岐点売上 | 固定費 ÷（1 − 変動費率）※変動費率＝(売上原価＋変動費)÷売上 | この売上で利益ゼロ |
| 損益分岐点販売数 | 損益分岐点売上 ÷ 1個あたり税抜売上 | 何個売れば黒字か |
| 安全余裕率 | （売上 − 損益分岐点売上）÷ 売上 | 売上が何%減ると赤字か |
| 目標達成に必要な販売数 | （固定費 ＋ 目標営業利益）÷ 1個あたり限界利益 | |

業界の一般的な目安（原価率・FL比率など）は出典によって幅があるため、断定せず「一般的な目安」として扱い、**自店の月次推移と理論値との比較**を優先します。

## 5. 診断の型（レポートの「原因」を書くとき）

数値の悪化を見つけたら、上から順に切り分けます。

| 症状 | 確認する数値 | 考えられる原因（仮説） | 打ち手の例 |
|---|---|---|---|
| 原価率（実際）が高い | 理論原価率も高いか | 理論も高い → 値付け・レシピの問題 | 価格改定、盛り量の標準化、原価の高い具材の代替 |
| | 理論は低く、原価差異が大きい | 廃棄・盛りすぎ・まかない・記録漏れ・仕入値上がり | 計量スプーン・盛り付け見本、仕込み量の見直し、仕入先比較 |
| 自販機の利益が薄い | 廃棄原価、設置手数料、補充人件費 | 期限切れロス、設置場所の売上歩合が重い、補充頻度が多い | 補充量を曜日別に調整、商品数を絞る、設置場所の条件交渉・移設 |
| キッチンカーの利益が薄い | 1日あたり販売数、出店料、燃料費 | 出店場所の集客力、売上歩合の高いイベント中心 | 出店先別の売上記録（摘要欄）と選別、定期出店先の確保 |
| 店舗が赤字 | 安全余裕率、人件費率、曜日別販売数 | 固定費（家賃・人件費）に対し販売数不足、閑散時間の人員過多 | シフト最適化、閑散時間帯の販促、客単価アップ（トッピング） |
| 全社の売上が季節で大きく落ちる | 年間推移 | 夏・冬の需要変動 | 季節メニュー、冷やしクレープ（自販機）の強化、繁忙期の出店増 |

打ち手の効果はシミュレーションシートと同じ式で試算し、「試算」「想定」と明記したうえで前提条件を書きます。
