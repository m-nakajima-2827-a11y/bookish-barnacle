# 月次収支レポート テンプレート

`scripts/analyze_workbook.py` の出力を事実データとして使い、次の構成で作成します。各ページに「タイトル／要点／詳細／図表案」を書くと、そのままスライド（PowerPoint・Googleスライド）に転記できます。

文体は簡潔な「です・ます調」。数値は税抜。ブックから出た数値は事実、原因は「仮説」、効果は「試算」と明記します。

---

## タイトル
`{店舗名} 収支レポート {YYYY年M月}`

## 1. 今月のサマリー
- **要点**：全社の売上・営業利益・営業利益率、前月比（年間推移から）を3行で。
- **詳細**：最も良かったチャネル／課題のあるチャネルを1つずつ。
- **図表案**：KPIカード4枚（売上高、営業利益、原価率、安全余裕率）。

## 2. チャネル別の現状
- **要点**：店舗・キッチンカー・自販機それぞれの売上、貢献利益、営業利益。
- **詳細**：配賦前（貢献利益）と配賦後（営業利益）の違いを1文で説明。
- **図表案**：チャネル別の積み上げ棒（売上原価／変動費／固定費／利益）。

## 3. 解決すべき課題
- 自動判定（要注意ポイント）と KPI から、優先度の高い順に最大3つ。
- 書き方：「◯◯チャネルの原価率が理論値より◯pt高い（実際◯%／理論◯%）」のように、数値と比較対象をセットで書く。

## 4. 課題の原因（仮説）
- `cost-calculation-guide.md` の「診断の型」で切り分けた結果を書く。
- 仮説ごとに「確認方法」（例：1週間、盛り付け量を計量して記録する）を添える。

## 5. 改善施策
| 優先度 | 施策 | 対象チャネル | 担当 | 期間 | 対応する課題 |
|---|---|---|---|---|---|
| 高 | | | | | 課題1 |
| 中 | | | | | 課題2 |
| 低 | | | | | 課題3 |

- 課題と施策は1対1以上で必ず対応させる。
- すぐできる（費用ゼロ・今月中）施策を最低1つ入れる。

## 6. 導入効果（試算）
- シミュレーションシートと同じ計算式で試算し、**「試算」「想定」と明記**。
- 例：「いちご生クリームを800円→850円（税込）にした場合、販売数が変わらない前提で月◯円の粗利増（試算）。販売数が◯%減っても粗利は同等（損益分岐）。」
- 前提条件（販売数、単価、原価、期間）を必ず併記。

## 7. KPI と目標
| KPI | 今月実績 | 来月目標 | 測り方 |
|---|---|---|---|
| 原価率（実際） | | | 月次損益 |
| 原価差異 | | | 月次損益 |
| 廃棄数（自販機） | | | 売上入力 |
| 損益分岐点販売数との差 | | | 月次損益 |

目標値はユーザーと合意した値か、実績からの改善幅（例：原価差異を半減）で置く。根拠のない業界水準を目標にしない。

## 8. 次のアクション
- 今週やること（担当・期限つき）を3つまで。
- ブック運用の改善点（例：棚卸の未入力、経費のチャネル未設定）があれば併記。

---

### 付記するとよい注意書き
- 本レポートは管理会計上の概算です。消費税・減価償却・申告に関する判断は税理士にご確認ください。
- 改善効果は試算であり、実績を保証するものではありません。
