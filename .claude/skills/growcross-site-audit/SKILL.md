# サイト診断・プロファイル作成

## 入力
- 対象: https://www.grow-cross.com（必要に応じて下層ページ）
- 既存のプロファイル: `.claude/skills/growcross-web-marketing/references/profile.md`

## 手順
### 1. ページの読み取り
次のページを読みます（存在するものだけ）。
トップ、会社概要、サービス一覧・各サービス詳細、料金、実績・事例、お客様の声、ブログ／コラム、お問い合わせ、資料請求、プライバシーポリシー、`/sitemap.xml`、`/robots.txt`

> サイトが読めない場合（ネットワーク制限など）は、読めなかったURLと理由を記録して止めます。内容を推測で埋めないでください。

### 2. プロファイルの更新
`profile.md` の各項目を、サイトの記載で埋めます。
- 記載があったものは「確認済み」とし、掲載URLを書きます。
- 記載がなく推定したものは「仮説」と明記します。
- 最後に、ご担当者へ確認が必要な質問を **重要なものだけ最大5つ** まとめます。

### 3. SEOの基本診断
| 観点 | 確認方法 | 判定の目安 |
|---|---|---|
| インデックス | Googleで `site:grow-cross.com` を確認、サーチコンソールの「ページ」レポート（利用できる場合） | 主要ページが検索結果に出ているか |
| robots / noindex | `robots.txt`、各ページの `<meta name="robots">` | 公開ページに noindex や Disallow がないか |
| サイトマップ | `/sitemap.xml` の有無と、サーチコンソールへの登録 | 主要ページが含まれているか |
| タイトル | 各ページの `<title>` | ページごとに固有、30〜35文字前後、主要キーワードを前半に |
| 説明文 | `<meta name="description">` | ページごとに固有、120文字前後、内容と行動を促す一文 |
| 見出し | h1 が1つ、h2・h3 が内容の構造に沿っているか | |
| 内部リンク | サービス・事例・記事・CVページ間のつながり | 孤立ページがないか |
| 構造化データ | Organization、BreadcrumbList、FAQPage 等 | 必要なものが入っているか |
| 表示速度・スマホ | PageSpeed Insights（利用できる場合） | 主要指標が「良好」か |
| 獲得キーワード | ラッコキーワードMCP `influx-statistics` / `influx-keywords` / `influx-pages` | 推移は `influx-trend` |

### 4. CV導線の診断
| 観点 | 確認内容 |
|---|---|
| 導線の数 | 各ページから問い合わせ・資料請求・相談へのボタンがあるか（ファーストビューとページ末尾） |
| 入口のハードル | 電話・フォーム以外の軽いCV（資料DL、事例集、チェックリスト）があるか |
| フォーム | 項目数、必須項目、入力エラー表示、送信完了ページ（GA4のキーイベント設定に使う） |
| 信頼材料 | 実績・事例・お客様の声・会社情報・料金の目安が載っているか |

### 5. 計測の確認
ページのHTMLから、GA4（`gtag` / `G-`）、Googleタグマネージャー（`GTM-`）、広告タグ、MAツールのタグを確認します。送信完了ページへの到達をキーイベントにしているかは、管理画面での確認が必要なため「要確認」とします。

## 出力
1. `profile.md` の更新
2. 診断レポート `growcross/reports/site-audit_YYYY-MM-DD.md`

```markdown
# サイト診断レポート（YYYY-MM-DD）
## 1. サマリー（3行）
## 2. 事実（確認できたこと）
## 3. 課題と原因（課題｜原因（事実/仮説）｜影響）
## 4. 改善案（優先度｜施策｜対象ページ｜担当（想定）｜期間の目安｜KPI）
## 5. 確認が必要な事項（最大5つ）
```

## 優先度の付け方
1. 検索結果に出ない原因（noindex、未登録、重大なエラー）
2. CVの計測ができていない
3. 主要ページのタイトル・説明文・見出し
4. CV導線・信頼材料
5. 表示速度・構造化データ
