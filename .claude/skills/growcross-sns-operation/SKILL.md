# SNS運用

## 現状
運用中: Instagram、Facebook（ご担当者回答）。アカウントURL・投稿頻度・フォロワー数は要確認です。新たなSNSは、この2つでの導線と計測が整ってから検討します。

## グロウクロスでの役割分担（案）
| SNS | 役割 | 主な投稿 | 導線 |
|---|---|---|---|
| Instagram | 専門性と人柄で信頼をつくる | 営業・AI活用のノウハウ図解（業種別）、支援の様子、コンサルタント紹介のリール | プロフィールのリンク（業種別ページ・相談予約）、ストーリーズのリンク |
| Facebook | 経営者・事業責任者への情報発信 | 記事の要約、事例、セミナー・相談会の告知 | 投稿内リンク（UTM付き）で記事・相談予約ページへ |

### 投稿テーマの例（4業種 × 3サービス）
| 業種 | 営業コンサル・伴走支援 | AIコンサル |
|---|---|---|
| 製造業 | ベテラン営業のノウハウを型にする、ルート営業から新規開拓へ | 見積・提案書づくりへのAI活用 |
| サービス業 | 紹介頼みから脱する集客と営業の仕組み | 問い合わせ対応・提案資料づくりの効率化 |
| 不動産 | 反響後の追客と商談化の型 | 追客メール・物件紹介文の作成支援 |
| 介護施設の運営事業者 | ケアマネ・病院など紹介元への定期訪問の型 | 記録・事務作業の効率化と、空いた時間の営業活動 |

※ 課題・効果の表現は仮説です。実際の支援事例に基づく内容に置き換えてください。

## 入力
- `profile.md` の運用中アカウント
- 今月公開した・公開予定の記事（`growcross/content/plan_YYYY-MM.md`）と事例

## 手順
### 1. アカウントの役割を決める
| SNS | 主な役割（目安） | 主なKPI |
|---|---|---|
| Instagram | 図解・事例で専門性と親しみを伝える | 保存数、プロフィールへのアクセス、リンククリック |
| X | 記事・お知らせの拡散、業界の話題への参加 | リンククリック、プロフィールへのアクセス |
| Facebook | 経営者・決裁者向けのお知らせ、セミナー告知 | リンククリック、申込 |
| YouTube | 解説・事例の動画 | 視聴維持率、概要欄リンクのクリック |
| LINE公式 | 既存顧客・見込み客への定期連絡 | 開封、クリック、相談予約 |

運用していないSNSを新たに始めるかは、担当者の工数と目的を確認してから決めます。

### 2. 投稿カレンダー（月次）
```bash
python -m dm_agent call plan_social_content_calendar '{"start_date":"YYYY-MM-DD","weeks":4,"target_industries":[...],"account_status":"active"}'
```
- 上記の出力（テーマ・形式・KPI・UTM付きのリンク先）をもとに、グロウクロスのサービスに合わせてテーマを置き換えます。
- 投稿の型: ①ノウハウ図解（保存狙い）②事例・お客様の声（信頼）③記事の要約（サイト誘導）④お知らせ・セミナー（CV）を、週2〜3回の想定で回します。

### 3. 投稿文の作成
```markdown
## <投稿日> <SNS> <形式>
- テーマ:
- 1行目（スクロールを止める一文）:
- 本文（3〜6行）:
- 画像構成（カルーセルの場合は1枚ずつ）:
- CTA: 「プロフィールのリンクから〇〇」など
- リンク先URL（UTM付き）:
- ハッシュタグ（必要な場合、5個前後）:
```
フィード投稿の本文中のURLはクリックできないSNSがあるため、プロフィールのリンクやストーリーズのリンクスタンプを使います。

### 4. 振り返り（月次）
投稿ごとの反応（保存・クリック等）はSNSのインサイトから、サイト訪問・資料DLはGA4（`utm_source` 別）から確認し、反応が良かったテーマを翌月に増やします。

## 出力
- `growcross/sns/plan_YYYY-MM.md`（投稿カレンダー）
- `growcross/sns/posts_YYYY-MM.md`（投稿文の下書き）

## 守ること
- 投稿の公開は承認後に行います。
- 顧客名・事例・写真は、掲載許可の範囲内で使います。
- 他者の画像・文章・音源は、権利を確認できたものだけを使います。
