# 分岐別メッセージ案（各3案）

`SKILL.md` の「分岐ルール」で振り分けた分岐ごとのひな形です。案1→案2→案3の順に送り、前の案で反応（リンククリック・予約・返信）があった方には次の案を送らず、担当者から個別に連絡します。

- 差し込み：`{お名前}` `{店舗名}` `{担当者名}` `{保有車種}` `{提案車種}` `{車検満了月}` `{URL}`（配信リストの列から差し込む）
- 配信日は相対タイミングです。分析の実施日から具体的な日付に置き換え、分岐ごとに同じ週に重ならないようずらします。
- 対象件数・特徴（多い車種など）は、分析結果から各分岐の見出しの下に追記して使います。
