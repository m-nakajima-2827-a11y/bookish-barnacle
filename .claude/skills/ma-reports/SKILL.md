# MA: レポート（ma_get_report）

```bash
python -m dm_agent call ma_get_report '{"report_type":"overview","period_start":"2026-09-01","period_end":"2026-09-30"}'
```

| report_type | 主な指標 | 改善の観点 |
|---|---|---|
| overview | カスタマー数、実名化率、配信可数、プッシュ許諾数、フォーム送信、匿名履歴の引き継ぎ数、スコア分布 | 実名化率が低い → ポップアップ・LPのフォーム改善 |
| email | シナリオ・種別ごとの配信／停止／開封率／クリック率／配信停止率 | 開封率が低い → 件名、クリック率が低い → 本文と資料の対象者のずれ |
| popup | 表示・クリック・CTR | CTRが低い → 表示条件（セグメント・秒数）と訴求の見直し |
| form | 送信数、新規カスタマー、匿名履歴ありの送信 | 匿名履歴ありの比率 → どの流入が実名化につながったか |
| push | 配信数・クリック率 | |
| scenario | 登録中・完了・離脱 | 離脱が多い → 営業対応が早く進んでいる（良い）か、条件が厳しすぎるか |
| segment | 各セグメントの人数 | |

## 月次報告での使い方
1. `overview` で全体を確認します。
2. `email` / `popup` / `form` で、施策ごとの反応を確認します。
3. `analyze-marketing-funnel` で、MAの反応が SQL・商談につながったかを確認します。
4. 改善提案（優先度・担当・時期）にまとめます。

開封率は画像表示に依存するため、参考値として扱ってください。
