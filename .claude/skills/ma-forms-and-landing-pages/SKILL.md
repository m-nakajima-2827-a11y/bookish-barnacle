# MA: フォーム・LP（ma_manage_form / ma_create_landing_page）

## フォーム（ma_manage_form）
| action | 用途 |
|---|---|
| create | 項目（`fields`）、リードイベント（資料DL / セミナー申込 / 問い合わせ）、資料ID、送信時タグ、自動返信、通知、同意チェック項目を定義 |
| submit | 送信処理 |
| get / list | 定義・送信数 |

### 送信時の処理順
1. 必須項目・メール形式のチェック
2. **名寄せ**: 同じメールアドレスのカスタマーがいれば同一人物として扱う
3. **実名化**: 送信元Cookieの匿名行動（LP閲覧・UTM・ポップアップ）を引き継ぐ → 最初の流入元（Instagram等）がリードに残る
4. 同意チェックがあればメール配信同意を記録（取得経路を保存）
5. 企業IDの付与: 会社のドメイン（フリーメールの場合は会社名）で同一企業をまとめる → 複数担当者の関与を評価できる
6. リード登録 → 自動スコアリング → MQLなら業界別育成シナリオ、ホットなら営業引き渡し
7. スコア加算・タグ付与・フォーム起点のシナリオ起動
8. 自動返信（請求資料の送付）・社内通知（Webhook / CRMタスク。連絡先はマスク）

既定のフォームは `config/clients/<client>.json` の `ma.forms` にあります（F-WP-MFG / F-WP-IT / F-SEMINAR / F-CONTACT）。

## LP（ma_create_landing_page）
```bash
python -m dm_agent call ma_create_landing_page '{"slug":"mfg-checksheet","title":"製造業向け 営業仕組み化チェックシート",
  "headline":"ベテラン営業の「勘と経験」を、チーム全員の型に。","form_id":"F-WP-MFG",
  "benefits":["属人化ポイントを30項目で点検","提案型営業への移行手順","週報の型づくり"],"theme_color":"#1F3A5F"}'
```
- 出力の `html` はレスポンシブ対応で、計測タグ・フォーム・個人情報の取り扱いへのリンクを含みます。
- `theme_color` は、Instagram投稿のデザインのトーンに合わせます。
- 作成後は `build-utm-tracking-url` で流入元ごとのURLを発行し、投稿・広告・ポップアップのリンク先にします。

## 注意
- 自動返信（請求された資料の送付）は取引メールとして、同意・頻度上限の対象外にしています。運用前に法務確認を推奨します。
- LPの文言は下書きです。事例の数値などは、顧客の了承を得た実績だけを載せてください。
