# キーワード戦略

## 入力
- `profile.md` のサービス・対象顧客・競合（「要確認」が多い場合は、サービス名と対象顧客だけ先に確認します）
- 既存のキーワードマップ `growcross/keyword-map.md`（2回目以降）

## 手順
### 1. 種キーワードの洗い出し
`profile.md` から、次の4種類を各3〜10語ずつ作ります。

| 種類 | 例（形式のみ。実際の語はサービスに合わせる） |
|---|---|
| サービス名・カテゴリ | 「〇〇 代行」「〇〇 制作」 |
| 課題・悩み | 「〇〇 できない」「〇〇 方法」 |
| 比較・選定 | 「〇〇 比較」「〇〇 費用」「〇〇 おすすめ」 |
| 地域・業種の掛け合わせ | 「〇〇 東京」「製造業 〇〇」（対象エリア・業種がある場合のみ） |

### 2. 拡張と指標の取得（ラッコキーワードMCP）
| 目的 | ツール |
|---|---|
| 関連語・サジェストの収集 | `related-keywords` / `suggest-keywords` |
| 質問形式の語（AI検索・FAQ用） | `question-search` |
| 月間検索数・SEO難易度・CPC・競合性・季節性 | `search-volume-history`（非同期。状態は `search-volume-history-status`、結果は `search-volume-history-results`） |
| 競合サイトの抽出 | `competitive`（競合ドメインで実行。グロウクロスは獲得キーワードが0件のため、自社ドメインでは結果が出ません） |
| 競合が獲得しているキーワード・集客ページ | `influx-keywords` / `influx-pages` |
| AIによる概要で引用されているキーワード | `influx-aio` |

> 数値はツールの取得値だけを使い、取得日を記録します。クレジットを消費するため、同じ条件での再取得は避けます。

### 3. 検索意図の分類と優先順位
| 検索意図 | 例 | 合うページ | 優先度 |
|---|---|---|---|
| 指名（会社名・サービス名） | 「グロウクロス」 | トップ・サービス | 最優先（自社名で1位を確実にとる） |
| 比較・検討（顕在層） | 「〇〇 費用」「〇〇 比較」 | サービス・料金・事例 | 高 |
| 課題解決（準顕在層） | 「〇〇 方法」「〇〇 失敗」 | ブログ記事 → 資料DL | 中 |
| 情報収集（潜在層） | 「〇〇 とは」 | 用語解説記事 | 低（競合が強い場合は後回し） |

優先度スコア（目安）= 事業との関連度（1〜3）× 検索意図の購買の近さ（1〜3）×（SEO難易度が低いほど高い（1〜3））
獲得キーワードが0件の段階では、**SEO難易度が低く（目安33以下）、購買に近い語** から始めます。

### 4. キーワードマップの作成
1つのキーワードグループに1ページを割り当て、同じ語を複数ページで狙わないようにします。

## 出力: `growcross/keyword-map.md`
```markdown
# キーワードマップ（取得日: YYYY-MM-DD / 出典: ラッコキーワード）
| 優先 | キーワードグループ | 主キーワード | 月間検索数 | SEO難易度 | 検索意図 | 割り当てページ（既存URL/新規） | 施策 | 状態 |
|---|---|---|---:|---:|---|---|---|---|

## AI検索（GEO）向けの質問リスト
| 質問 | 回答を載せるページ | 状態 |

## 広告向けキーワード（購買に近い語）と除外キーワード案
```

## 守ること
- 実在する競合の社名・商標を、広告の訴求や記事で否定的に扱う案は出しません。
- 検索数の少ない語でも、BtoBで購買に近い語は残します（月間検索数だけで切り捨てない）。
