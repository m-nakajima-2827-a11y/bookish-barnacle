# 週次チェック・月次レポート

## データの取得元
| データ | 取得方法 |
|---|---|
| 獲得キーワード数・推定流入 | ラッコキーワードMCP `influx-statistics` / `influx-trend` / `influx-keywords` |
| 狙ったキーワードの順位 | `search-rank-history`（非同期） |
| AIによる概要での引用 | `influx-aio` |
| 流入・CV（GA4）・検索クエリ（サーチコンソール） | どちらも設定済み。Googleスプレッドシートへの定期エクスポート（Looker Studio やアドオン経由）を用意し、Google Sheets コネクタで読み取るのが手軽です。未準備の間は担当者からエクスポートを受け取ります |
| 相談予約 | 予約ツール導入後は、GA4のキーイベント `consultation_booked` と予約ツールの予約数を照合 |
| ファネル（流入→資料DL→MQL→SQL→商談→受注） | `python -m dm_agent call analyze_marketing_funnel '{...}' --client growcross` |
| MAの実績 | `ma_get_report`（overview / email / popup / form / scenario） |
| 広告 | 媒体の管理画面または `optimize_lead_gen_campaigns` の実績 |

データがない項目は空欄とし、「データ未取得」と明記します。前回の数値と比べるときは、期間と出典を揃えます。

## 週次チェック（毎週月曜の想定・15分で読める分量）
```markdown
# 週次チェック（YYYY-MM-DD〜YYYY-MM-DD）
## 1. 今週の数字（前週比）: 流入／CV（問い合わせ・資料DL）／商談
## 2. 気になる変化（事実）と考えられる原因（仮説）
## 3. 今週のタスク（優先度｜タスク｜担当（想定）｜期限｜使うSkill）
## 4. 承認が必要な事項
```

## 月次レポート（提案書の構成）
| # | ページ | 内容 |
|---|---|---|
| 1 | 背景・目的 | 今月の目標とKPI |
| 2 | 現状 | KPIの実績と前月比・目標比（表） |
| 3 | 解決すべき課題 | 数字から見える課題（最大3つ） |
| 4 | 課題の原因 | 事実と仮説を分けて記載 |
| 5 | 改善の方針 | 来月の重点（1つに絞る） |
| 6 | 具体的な施策 | 施策｜対象｜担当（想定）｜期間 |
| 7 | 期待効果 | 「想定」と明記した試算 |
| 8 | 体制 | 社内・外部の役割分担 |
| 9 | スケジュール | 週単位 |
| 10 | KPI | 来月の目標値と測り方 |
| 11 | 今後の展開 | 3か月の見通し |
| 12 | まとめ・次のアクション | 承認事項と期限 |

各ページに「タイトル／要点（1〜2行）／詳細／図表案」を書き、PowerPoint・Googleスライドにそのまま移せる形にします。

## KPIツリー（目安）
```
問い合わせ・資料DL数 ＝ サイト流入数 × CVR
  サイト流入数 ＝ 自然検索 ＋ 広告 ＋ SNS ＋ 指名・直接 ＋ メール
  CVR ← LP・フォーム・導線の改善
商談数 ＝ リード数 × 商談化率 ← 育成・初回接触の速さ・対象者の一致
```

## 出力
- 週次: `growcross/reports/weekly_YYYY-MM-DD.md`
- 月次: `growcross/reports/monthly_YYYY-MM.md`

## 守ること
- 数値は取得したデータのみを使い、出典と期間を明記します。
- 成果の要因を断定せず、「〜の可能性があります（仮説）」と書き分けます。
