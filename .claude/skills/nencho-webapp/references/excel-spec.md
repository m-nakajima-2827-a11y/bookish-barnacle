# 元Excel（年末調整計算シート 令和８年用）との対応表

元ファイル：国税庁「年末調整計算シート（令和８年用）」`keisansheet.xlsm`（14シート、VBAは空マクロのみ）。
元ファイルでは計算シートの入力欄（①③④⑥⑫〜⑳、Ⓐ〜Ⓘ、㉔など）を**担当者が申告書を見て手入力**します。
本アプリの Excel 出力は、同じセル番地のまま**それらを各シートからの関数参照に置き換え**、自動反映にしています。

## 1. シート構成

| 元ファイル | 出力Excel | 役割 | 変更点 |
|---|---|---|---|
| 計算シート | 計算シート | ①〜㉞の計算 | 入力欄→他シート参照の関数に。セル番地は同一 |
| 集計シート | 集計シート | 月別の給与・賞与 | L列「うち小規模企業共済等掛金」を追加 |
| 扶養申告書（画像） | 扶養申告書 | 扶養親族の入力・自動区分 | 画像→入力表＋判定関数 |
| 基礎申告書（画像） | 基礎申告書 | 合計所得・基礎控除 | 同上 |
| 配偶者申告書（画像） | 配偶者申告書 | 配偶者（特別）控除 | 同上 |
| 特定親族申告書（画像） | 特定親族申告書 | 特定親族特別控除 | 扶養申告書から自動転記 |
| 所得金額調整申告書（画像） | 所得金額調整申告書 | 適用の有無 | 要件を自動判定 |
| 保険申告書（画像） | 保険申告書 | 生保・地震・社保・小規模共済 | 計算式Ⅰ〜Ⅲを関数化 |
| 住借申告書（画像） | 住借申告書 | 住宅借入金等特別控除 | 残高×控除率と限度額 |
| 源泉徴収簿（画像） | 源泉徴収簿 | 月別＋年末調整欄 | 集計・計算シートを参照 |
| 入力のしかた（3シート） | （アプリ画面の説明文） | — | 画面の説明文に統合 |
| 各種申告書・参考情報 | 各種申告書・参考情報 | 国税庁リンク | 令和8年分URLに更新 |
| — | 控除テーブル | 控除額・所得要件の表 | 新設（法改正時はここを更新） |
| — | 確定申告チェック | 確定申告の要否 | 新設 |

全シート**保護なし**。黄色＝入力セル、白＝関数、橙＝アプリで手入力（上書き）した値。

## 4. 申告書シートの主なセル

- **扶養申告書**：本人 C3（障害者）・C4（寡婦/ひとり親）・C5（勤労学生）・C6（同一生計配偶者の障害者区分）・C7（同一生計配偶者の判定）。
  扶養親族は10〜19行（B氏名〜J障害者区分が入力、K年齢・L区分・M扶養控除・N特定親族特別控除・O障害者控除・P 23歳未満・Q源泉控除対象が関数）。
  C21〜C29＝Ⓐ〜Ⓘ、C31＝23歳未満の扶養親族の有無、C32＝特定親族特別控除の合計。
- **基礎申告書**：C3＝⑪、C4＝給与以外の所得、C5＝合計所得、C6＝区分Ⅰ、C7＝基礎控除額。
- **配偶者申告書**：C3有無、C6生年月日、C7配偶者の合計所得、C9年齢、C12区分Ⅱ、C13配偶者控除、C14配偶者特別控除、C16合計。
- **保険申告書**：生保 5〜14行（C区分・D新旧・E金額）→K5〜K14、地震 18〜22行→K18〜K20、社保 26〜31行→K26・K27、小規模 35〜38行→K35。
- **住借申告書**：C3残高、C4控除率、C5限度額、C6直接入力、C7控除額。
- **控除テーブル**：B3対象年、B4扶養の所得要件、B5特定親族上限、B11〜B20控除額、D5:E11基礎控除、G5:J15・H17:J17配偶者、L5:M15特定親族。
