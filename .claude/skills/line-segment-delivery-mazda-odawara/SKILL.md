# マツダ小田原 LINEセグメント配信（OnetoOne）

マツダ小田原のLINEお友だちを、**車種・年齢・店舗・車検時期・年収**で分け、OnetoOne機能で一人ひとりに合ったメッセージを届けるためのSkillです。

このSkillで作るもの:

| No. | 成果物 | 章 |
|---|---|---|
| ① | お友だちの分析（車種・年齢・店舗・車検時期） | 2章 |
| ② | 年収別・ローン設定可能な範囲の適正価格と車種一覧 | 3章 |
| ③ | 年収6区分 × 各3案のセグメント配信メッセージ（配信時期つき） | 4章 |
| ④ | 1回目〜4回目のステップ配信メッセージ | 5章 |
| ⑤ | 季節のメンテナンス情報・おすすめ車種の配信メッセージとバナー案（各2案） | 6章 |

### 0-1. 入力データ（LINEシステムからのエクスポート）

|---|---|---|---|

### 0-2. 年収データの取り扱い（必ず守る）

- 年収は**アンケート・商談時の自己申告など、本人が利用目的に同意して提供したデータのみ**使います。推測で年収区分を付けません。
- メッセージ本文に**年収・ローン審査・「あなたの収入なら」などの表現を書きません**。お客さまは、自分がどのセグメントで配信されているかを意識しない文面にします。
- 年収区分が未登録のお友だちは「年収不明」とし、車種・車齢・車検時期のセグメントで配信します（年収で無理に分けない）。
- ローンの可否は信販会社の審査で決まります。3章の一覧は**提案時の目安**であり、審査結果を約束するものではありません。

### 0-3. 不足時に確認する情報（重要なものだけ）

1. 店舗名・定休日・営業時間（配信日時と予約導線の設定に必要）
2. 現在のキャンペーン・取扱車種の最新価格表（2026年時点の価格に更新するため）
3. ローン条件（金利・残価設定型クレジットの有無、最長回数）
4. 予約導線（LINE予約フォーム・電話・Webのどれを使うか）

不足している場合は、`{ }` の差し込み項目のまま出力し、確認事項として一覧にします。

## 1. 配信ルール（全メッセージ共通）

| 項目 | ルール |

| 配信頻度 | 1人あたり**月2回まで**（車検・点検の個別連絡は除く）。ブロック率が上がった場合は月1回に下げる |
| 配信時間 | 平日 12:00〜13:00 / 19:00〜20:30、土日 9:30〜10:30（**仮説**。開封データで検証して調整） |
| 配信しない日 | 店舗の定休日・年末年始休業・GW/お盆休業の期間（問い合わせに即日対応できないため） |
| 1通の構成 | 吹き出し1〜2個 ＋ 画像（バナー）1枚。本文は **200字前後** を目安 |
| 差し込み | `{お名前}` `{担当者名}` `{店舗名}` `{車種}` `{車検満了月}` `{予約URL}` |
| CTA | 1通につき1つ（来店予約・試乗予約・見積依頼・返信のいずれか） |
| 返信対応 | OnetoOneで返信が来たら、営業時間内は **当日中** に担当者が返信 |
| 除外 | 商談中・成約直後（3か月以内）・ブロック・配信停止希望のお友だち |

### 表示の注意（景品表示法・割賦販売法）

- 価格は**税込の総額**で表示します。「最安」「どこよりも安い」など根拠のない表現は使いません。
- 月々の支払額を表示する場合は、**現金価格・頭金・支払回数・実質年率・支払総額**（残価設定型の場合は残価額も）を併記します。表示しない場合は「お見積りでご案内します」とします。
- キャンペーン・特典は、期間・条件・対象車種を明記します。

## 2. ① お友だちの分析（車種・年齢・店舗・車検時期）

### 2-1. 集計の手順

1. 配信対象を絞る（ブロック・配信停止・商談中を除外）
2. 4つの軸で単純集計する
3. 「車検時期 × 車種」「年齢 × 車種」「店舗 × 車検時期」でクロス集計する
4. 下表の基準でセグメントを付与する
5. 配信優先度（A〜C）を付ける

### 2-2. 分析軸と区分

| 軸 | 区分 | 見るポイント |
|---|---|---|
| 車種 | 軽（フレア等）／コンパクト（MAZDA2）／SUV小型（CX-3・CX-30）／SUV中型（CX-5）／SUV大型（CX-60・CX-80）／セダン・HB（MAZDA3）／スポーツ（ロードスター）／その他・他メーカー | 保有車種の構成比。乗り換え先候補（上位車種・同クラス新型） |
| 年齢 | 20代以下／30代／40代／50代／60代／70代以上 | ライフイベント（結婚・出産・子どもの進学・定年）と車の買い替え時期の関係 |
| 店舗 | {店舗名A}／{店舗名B}／… | 店舗別のお友だち数・車検到来数（入庫・来店予約の受け入れ枠の計画に使う） |
| 車検時期 | 3か月以内／4〜6か月／7〜12か月／13〜24か月／不明 | **4〜6か月前**が乗り換え提案の開始時期、**3か月以内**が車検予約の案内時期（**仮説**） |
| 車齢 | 3年未満／3〜5年／5〜7年／7年以上 | 初回車検（3年）・2回目車検（5年）・3回目車検（7年）が乗り換え検討の節目 |

### 2-4. セグメントと配信優先度

| 優先度 | 条件 | 主な配信内容 |
|---|---|---|
| A | 車検満了まで4〜6か月 かつ 車齢5年以上 | 乗り換え提案（車検費用との比較・下取り査定） |
| A | 車検満了まで3か月以内 | 車検予約の案内（早期予約特典がある場合は明記） |
| B | 車検満了まで7〜12か月 かつ 車齢3年以上 | 新型・おすすめ車種の情報、試乗会の案内 |
| B | 最終来店から12か月以上 | 点検・メンテナンスの案内（休眠の掘り起こし） |
| C | 上記以外 | 季節メンテナンス情報・イベント情報（月1回） |

### 2-5. 所見の書き方

- 数値はCSVの集計結果のみを書きます。データにない傾向は「**仮説**」と明記します。
- 所見は「誰に・いつ・何を送るか」につながる形で書きます。
  - 例：「CX-5保有の40代で車検4〜6か月前が{n}人。CX-80（3列シート）とCX-5新型の比較提案を11月に配信する。」

## 3. ② 年収別・適正価格の車種一覧（ローン設定可能な範囲）

### 3-1. 試算の考え方（**仮説・目安**）

| 前提 | 設定値（目安） | 変更方法 |
|---|---|---|
| 年間返済額の上限 | 年収の **10%**（自動車ローン単体の目安。住宅ローン等がある場合は下げる） | 店舗・信販会社の基準に合わせて変更 |
| 返済期間 | 5年（60回） | 残価設定型クレジット・最長回数に合わせて変更 |
| 頭金・下取り | 50万円 | お客さまの下取り車の査定額で置き換え |
| 車両総額の目安 | 年間返済額上限 × 5年 ＋ 頭金・下取り | 金利を含む「返済総額ベース」の概算 |

> 計算式：**車両総額の目安 ＝ 年収 × 10% × 5年 ＋ 頭金・下取り（50万円）**
