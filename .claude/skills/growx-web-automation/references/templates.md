## 1. 競合SEO分析表（competitor-seo_YYYY-MM.md）
```markdown
# 競合SEO分析（取得日: YYYY-MM-DD / 出典: ラッコキーワード）
## 競合サイト一覧
| 競合ドメイン | 推定流入 | 獲得KW数 | 主力ページ（上位3） | 領域（営業改善/WEB改善/AI活用） |
## 競合が獲得し、GrowXが未獲得のキーワード
| キーワード | 月間検索数 | SEO難易度 | 競合順位（ドメイン） | 検索意図 | 領域 | 取得日 |
## 示唆（事実と仮説を分けて記載）
```

## 2. 重複判定表（duplicate-check_YYYY-MM.md）
```markdown
| キーワードグループ | 主キーワード | 既存記事URL | 現在順位（出典） | GSC表示回数 | 判定（新規/リライト/統合/見送り） | 理由 | 優先度スコア |
```

## 3. コンテンツカレンダー（content/calendar.csv）
列（この順で固定・UTF-8 BOM付きでExcel対応）:
`ID,公開予定日,領域,主キーワード,サブキーワード,検索意図,種別,タイトル案,CTA,担当,状態,公開URL,備考`

- 領域: 営業改善／WEB改善／AI活用
- 種別: 新規／リライト／統合
- CTA: 無料診断／資料請求／お問い合わせ
- 状態: 企画中 → 構成案承認待ち → 執筆中 → 入稿パッケージ承認待ち → ChatGPT登録待ち → 公開済み → 効果測定中
- 範囲: 常に「今日から6か月先」まで埋めます（週1本の想定。本数は担当者の指示で変更）。

## 5. 月次改善レポート（reports/monthly-seo_YYYY-MM.md）
growcross-reporting の月次構成（12ページ: 背景・目的／現状／課題／原因／方針／施策／期待効果／体制／スケジュール／KPI／今後の展開／まとめ・次のアクション）に従い、各ページに「タイトル・要点・詳細・図表案」を記載します。KPIは以下を必ず含めます（取得できない項目は「データ未取得」）。

| KPI | 出典 |
|---|---|
| 獲得キーワード数（100位以内／10位以内） | ラッコ `influx-statistics` |
| 推定流入 | ラッコ `influx-statistics` / `influx-trend` |
| 狙ったKWの順位 | ラッコ `search-rank-history` |
| 自然検索のクリック・表示回数・CTR | GSC CSV |
| 記事経由のCV（無料診断・資料請求・お問い合わせ） | GA4 CSV |
| 公開本数（計画比） | calendar.csv |
