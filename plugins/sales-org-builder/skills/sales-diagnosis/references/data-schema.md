# 案件データの標準項目と分類コード

## 案件データシートの列

| 列 | 項目 | 型・例 | 必須 |
|---|---|---|---|
| A | 案件ID | 文字列 | ○ |
| B | 顧客名 | 文字列（社外共有時は匿名化） | ○ |
| C | 業界 | 製造／IT／金融／小売／医療／その他 | ○ |
| D | 企業規模 | 従業員数の区分（〜100／〜1,000／1,000〜） | |
| E | 相談部署・決裁者 | 文字列 | |
| F | リード経路 | 紹介／問い合わせ／展示会・セミナー／アウトバウンド／既存深耕 | ○ |
| G | 相談内容（サービス区分） | 顧客の商材に合わせて定義 | ○ |
| H | 顧客課題 | コスト／納期／人材不足／品質／技術／その他 | |
| I | 結果 | 受注／失注／継続中／保留 | ○ |
| J | 受注・失注理由コード | 下表 | ○（受注・失注のみ） |
| K | 理由の原文 | 文字列 | |
| L | 金額 | 数値（税抜） | |
| M | 粗利額 | 数値 | |
| N | 初回接点日 | 日付 | ○ |
| O | 提案日 | 日付 | |
| P | 受注・失注日 | 日付 | |
| Q | 最終到達ステージ | 標準ステージ①〜⑨ | ○ |
| R | 接点数・提案回数 | 数値 | |
| S | 見積回数・差し戻し回数 | 数値 | |
| T | 引き継ぎ後のトラブル | なし／認識違い／手戻り／赤字／納期遅延 | |
| U | 追加・継続受注 | あり／なし | |
| V | 営業担当 | 文字列（分析後の共有時は匿名化を検討） | |

## 受注理由コード

| コード | 内容 |
|---|---|
| W1 | 技術力・専門性 |
| W2 | 品質・実績への信頼 |
| W3 | 価格 |
| W4 | 対応スピード・柔軟性 |
| W5 | 提案内容が課題に合っていた |
| W6 | 会社・グループの信用、既存取引 |
| W9 | その他 |

## 失注理由コード

| コード | 内容 |
|---|---|
| L1 | 価格 |
| L2 | 時期（予算化されず、延期） |
| L3 | 競合に負けた |
| L4 | 要件・範囲が合わない |
| L5 | 提案不足（課題の把握不足、提案が遅い） |
| L6 | 決裁者に届かなかった |
| L7 | 社内事情（体制・リソースで受けられない） |
| L9 | その他・不明 |

L9が全体の2割を超える場合は、失注理由の記録ルールそのものを課題として挙げる。
