# 関係者ヒアリングガイド

1人30〜45分を目安にする。冒頭で「個人の評価ではなく、仕組みを良くするための聞き取りである」と伝える。

## 営業担当者向け

1. 直近で受注できた案件と、決め手になったと思うことは何か
2. 直近で失注した案件と、振り返ってどこで変えられたか
3. 初回商談で必ず確認していることは何か。確認しづらいことは何か
4. 提案書・見積を作るとき、時間がかかる作業はどこか
5. 引き継ぎ先（開発・制作・運用など）に渡すとき、よく聞き返されることは何か
6. 案件の見込み度を、何を基準に判断しているか
7. 社内で参考にしている資料・人は誰か（暗黙のナレッジの所在）
8. ツール（CRM等）の入力で負担に感じていることは何か

## 営業責任者向け

1. 営業メンバーの間で、成果の差が出ていると感じるのはどの工程か
2. 案件レビューの現在の進め方と、判断に困る場面
3. 売上予測が外れる典型的なパターン
4. 新人が独り立ちするまでの期間と、つまずく点
5. 標準化で「変えてほしくないこと」（強みとして残したいこと）

## 引き継ぎ先の責任者向け（PM・開発責任者・制作進行・CSなど）

1. 営業から受け取る情報で、不足しがちなものは何か
2. 見積の差し戻しや前提の食い違いが起きた最近の例
3. 営業が顧客に約束した内容と、実際の対応範囲がずれた例
4. 引き継ぎで最低限そろっていてほしい情報は何か
5. 営業の提案段階で関わりたいタイミングはあるか

## 記録の型

| 項目 | 内容 |
|---|---|
| 対象者の役割 | 営業担当／営業責任者／引き継ぎ先 |
| 発言要旨 | 事実と意見を分けて書く |
| 該当する課題領域 | 提案／ヒアリング／連携／案件管理 |
| データとの照合 | 一致／食い違い／データなし |
