# 営業AI活用プロンプト集

各プロンプトの `{{ }}` を、顧客のテンプレートの項目名に置き換えて使う。AIの出力は、担当者が必ず確認してから記録・送付する。顧客情報を外部のAIサービスに入力する前に、社内のセキュリティ規程を確認する。

## 1. 商談前：課題仮説の作成

```
次の企業について、初回商談で確認すべき課題仮説を3つ作ってください。
- 企業情報: {{公式サイト・ニュース・求人情報の要約}}
- 当社のサービス: {{サービス一覧}}
各仮説について「想定される課題」「その根拠（公開情報のどこから推定したか）」「確認するための質問」を書いてください。根拠のない推測は「推測」と明記してください。
```

## 2. 商談後：議事録から1ページ案件サマリーを作る

```
次の商談議事録から、1ページ案件サマリーを作ってください。
項目: 顧客の目的／現状と課題／課題の原因／優先順位／提案するサービス／想定効果／懸念事項／次回行動／社内で確認が必要な事項
議事録に書かれていないことは推測で埋めず「未確認」と書いてください。
議事録: {{議事録}}
```

## 3. ヒアリング漏れのチェック

```
次の商談記録を、ヒアリングシートの必須項目と照合してください。
必須項目: {{★のついた項目一覧}}
項目ごとに「確認済み（記録の該当箇所）」「一部のみ」「未確認」を表で示し、未確認の項目について次回の質問案を書いてください。
商談記録: {{記録}}
```

## 4. 提案書の初稿

```
次の1ページ案件サマリーをもとに、提案書の12項目（顧客の事業目的、現状と課題、課題の原因、解決方針、提案範囲、体制・役割分担、工程・スケジュール、{{差別化要素}}、費用・前提条件、期待効果、リスクと対応策、次のステップ）の初稿を作ってください。
金額・期間・効果の数値はサマリーにあるものだけを使い、ない場合は「要確認」と書いてください。
サマリー: {{サマリー}}
```

## 5. 顧客の要望を引き継ぎ先向けの要件に整理する

```
次の顧客の要望（日本語の商談メモ）を、{{引き継ぎ先}}が見積・着手できる形に整理してください。
出力: 目的／対象ユーザー／必須要件／希望要件／対象外／前提条件／未確定事項（質問形式）
あいまいな表現（「いい感じに」「なるべく早く」など）は、未確定事項として質問に変換してください。
メモ: {{メモ}}
```

## 6. 失注理由の分類

```
次の失注案件の記録を、失注理由コード（L1 価格／L2 時期／L3 競合／L4 要件不一致／L5 提案不足／L6 決裁者に届かない／L7 社内事情／L9 その他）に分類してください。
案件ごとに、コード・根拠となる記述・確信度（高／中／低）を表で示してください。
記録: {{記録}}
```

## 7. ロールプレイの顧客役

```
あなたは{{業界}}の{{役職}}です。表向きは「{{表向きの相談}}」で相談に来ていますが、本当の課題は「{{本当の課題}}」です。予算は{{予算の状況}}、決裁者は{{決裁者}}です。
営業担当者が適切に質問した場合だけ、本当の課題・予算・決裁者を明かしてください。途中で「{{反論}}」と反論してください。
15分の商談が終わったら、役を降りて、営業担当者の良かった点と、確認できなかった項目を伝えてください。
```
