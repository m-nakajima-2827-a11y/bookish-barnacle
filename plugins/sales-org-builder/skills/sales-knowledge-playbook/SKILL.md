# ナレッジ蓄積と定着（プレイブック・育成・AI活用）

標準プロセスとテンプレートを作っても、使われなければ元の属人的なやり方に戻る。このスキルは、成功・失注の知見を再利用できる形で残し、マニュアル・ロールプレイ・AIで日々の営業に組み込むためのものである。

AIの導入は、プロセス・入力項目・テンプレートが統一された後に行う。元のデータがばらばらなままでは、AIを使っても営業品質は均一化しない。ユーザーがAI活用から始めたいと言った場合も、この順序を説明したうえで、必要な前提（テンプレートの有無）を確認する。

## 作成できるもの

| 成果物 | 形式 | 詳細 |
|---|---|---|
| 営業事例データベース | Googleスプレッドシート | `references/playbook-specs.md` の「事例DB」 |
| 営業マニュアル（プレイブック） | Googleドキュメント | 同「プレイブックの目次」 |
| ロールプレイのシナリオと評価シート | Googleドキュメント＋スプレッドシート | 同「ロールプレイ」 |
| 新人育成計画（30・60・90日） | Googleドキュメント | 同「育成計画」 |
| AI活用プロンプト集 | Googleドキュメント | `references/ai-prompts.md` |

## 手順

### 事例データベース
1. 11項目の登録フォーマットでスプレッドシートを作り、選択式の項目にはプルダウンを設定する。
2. 営業診断の受注・失注案件から、代表的な3〜5件を初期登録の例として入れる（ユーザーから提供された事実のみ。推測で埋めない）。
3. 登録ルール（誰が・いつ・何件）と、検索のしかた（業界・課題・サービスでの絞り込み）を冒頭に書く。

### 営業マニュアル
1. 標準営業プロセス、テンプレート、提案パターン、KPI・レビューの各成果物へのリンクを集める。
2. プレイブックの目次に沿って、各章を「目的 → やること → 使うテンプレート → よくある失敗」の順で書く。
3. 1章は2ページ以内にする。詳しい内容はリンク先に任せる。

### ロールプレイ
1. 営業診断の失注理由と、ヒアリングで漏れやすい項目から、練習テーマを3〜5個選ぶ。
2. テーマごとに、顧客役の設定（業界、役職、課題、本音、出しやすい反論）と、営業役のゴールを書く。
3. 評価シートは、ヒアリングシートの必須項目を確認できたか、課題を顧客の言葉で要約できたか、次回行動を合意できたか、で採点する。
4. AIを顧客役にする場合のプロンプトは `references/ai-prompts.md` を使う。

### AI活用
`references/ai-prompts.md` から、顧客のテンプレートに合わせたプロンプトを選び、出力の形式をテンプレートの項目名に合わせて書き換える。AIの出力は必ず担当者が確認してから記録・送付する、と運用ルールに書く。顧客情報を外部のAIサービスに入力する場合は、社内のセキュリティ規程を確認するよう注記する。

## Googleファイルの作り方

作成前に `google-workspace` スキルを読み込む。新規ファイルはGoogleドライブで作り、中身はGoogleスプレッドシート・Googleドキュメントのコネクタで書き込む。変更は同じファイルに加え、リンクを変えない。マニュアルから各成果物へは、ファイルのリンクで参照する。
