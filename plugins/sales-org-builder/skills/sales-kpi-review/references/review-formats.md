# レビューのフォーマットとダッシュボードの構成

## 週次案件レビュー（意思決定の場）

**列**: 案件ID｜顧客名｜顧客の課題｜現在のステージ｜案件スコア・区分｜受注予定額｜粗利益｜受注予定時期｜決裁者｜競合｜現在の障害｜次回行動｜期限｜支援してほしいこと｜決定事項

**会議の進め方（60分の例）**
1. 前回の決定事項の確認（5分）
2. A区分の案件（1案件5分）
3. 受注予定日が近いB区分の案件（1案件3分）
4. 段階を戻す案件の確認（次へ進む条件を満たしていないもの）（5分）
5. 支援依頼の割り当て（担当・期限）（5分）

**ルール**
- 状況報告は事前にシートへ記入し、会議では読み上げない
- 各案件で「次の一手」と「期限」を必ず決める

## 月次傾向レビュー

| 観点 | 見るもの | 決めること |
|---|---|---|
| 業界別の受注率 | 前月・前年同月との比較 | 注力業界の見直し |
| 提案サービス別の受注率 | 入口サービスごとの受注率 | 提案パターン表の更新 |
| 失注理由 | コード別の件数推移 | 対策の担当と期限 |
| ステージ移行率 | 担当者別・段階別 | 支援・育成が必要な工程 |
| チャネル別の商談化率 | リード経路別 | マーケティングとの連携事項 |
| 既存顧客からの追加受注率 | 顧客別 | 定例会・追加提案の計画 |
| 差し戻し・手戻りの原因 | 原因の分類 | テンプレートの改訂 |

## KPIダッシュボードの構成（Googleスプレッドシート）

| シート | 内容 |
|---|---|
| 元データ | CRMのエクスポートまたは案件管理シートを貼り付け（または参照） |
| 設定 | 期間、目標値、ステージ名、理由コード |
| サマリー | 3階層のKPIの当月値・前月値・目標値・差分を1画面に |
| ファネル | ステージ別の件数と移行率（降順の横棒グラフ） |
| 推移 | 月別の受注数・受注額・受注率（折れ線） |
| 失注分析 | 理由コード別の件数・構成比 |
| 品質 | ヒアリング充足率、差し戻し率、引き継ぎ不備件数の推移 |

集計はすべて数式（COUNTIFS、SUMIFS、AVERAGEIFS、QUERY）で作り、元データの更新だけで最新化できるようにする。
