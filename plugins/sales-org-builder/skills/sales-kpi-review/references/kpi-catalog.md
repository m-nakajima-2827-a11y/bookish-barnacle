# KPIカタログ（3階層）

## 新規営業KPI

| 指標 | 定義・計算式 | 種別 |
|---|---|---|
| ターゲット企業数 | 当期にアプローチ対象としてリスト化した企業数 | 先行 |
| 有効接点数 | 担当者・決裁者と会話できた接点の数 | 先行 |
| 初回面談数 | ②初回接点を完了した件数 | 先行 |
| 課題確認済み案件数 | ③課題ヒアリングを完了した件数 | 先行 |
| 提案数 | ⑥提案・見積を提出した件数 | 先行 |
| 受注数・受注率 | 受注件数、受注 ÷（受注＋失注） | 結果 |
| 平均受注単価 | 受注金額合計 ÷ 受注件数 | 結果 |
| 商談期間 | 初回接点日から受注日までの平均日数 | 結果 |
| 失注理由 | 失注理由コード別の件数・構成比 | 結果 |

## 既存営業KPI

| 指標 | 定義・計算式 | 種別 |
|---|---|---|
| 定例会実施率 | 定例会を実施した顧客数 ÷ 対象顧客数 | 先行 |
| 顧客満足度 | 定期アンケートの平均点（方法を定義する） | 結果 |
| 追加提案数 | 既存顧客への提案件数 | 先行 |
| アップセル・クロスセル受注額 | 既存顧客からの追加受注金額 | 結果 |
| 契約継続率 | 更新した契約数 ÷ 更新対象の契約数 | 結果 |
| 横展開件数 | 別サービス・別部署・グループ会社への展開件数 | 結果 |

## 組織品質KPI（提案品質・引き継ぎ品質）

| 指標 | 定義・計算式 | 種別 |
|---|---|---|
| ヒアリング項目の充足率 | 必須項目の記入数 ÷ 必須項目数（案件平均） | 先行 |
| 提案書レビュー実施率 | 提出前にレビューした提案書 ÷ 提出した提案書 | 先行 |
| 見積差し戻し率 | 差し戻しがあった見積依頼 ÷ 見積依頼数 | 結果 |
| 引き継ぎ不備件数 | キックオフ前レビューで「NG」になった項目数 | 結果 |
| 見積工数と実績工数の差 | （実績工数 − 見積工数）÷ 見積工数 | 結果 |
| 認識違いによる手戻り件数 | 顧客との認識違いが原因の手戻り件数 | 結果 |
| 事例の登録数 | 当期に登録した成功・失注事例の件数 | 先行 |

組織品質KPIは、標準化の効果を最も直接的に示す。売上が動く前に改善が見えるため、導入初期の報告ではこの階層を中心に置く。
