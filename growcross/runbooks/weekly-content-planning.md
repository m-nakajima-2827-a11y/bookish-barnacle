# 週次コンテンツ企画（毎週月曜 7:43 JST 自動実行）

実行者: AI社員 `growx-ai-employee` ／ Skill: `growx-web-automation`（ステップ0・3・4・5）
所要: 1回あたりラッコキーワードのクレジット消費は最小限（新規候補の検索数取得のみ）

## 手順
1. **入力確認（ステップ0）**
   - `profile.md` の「要確認」項目、`growcross/data/` の新着ファイル、`growcross/content/calendar.csv`、前週の `weekly-plan_*.md` を読みます。
   - calendar.csv がなければテンプレート（`references/templates.md` の列）で作成します。
2. **前週の進捗確認**
   - calendar.csv の「状態」を見て、期限切れ・停滞（2週間以上同じ状態）の企画を抽出します。
3. **企画の補充（ステップ3・4）**
   - 今日から6か月先までの枠に空きがあれば、`growcross/keyword-map.md` と最新の重複判定表から優先度の高い順に企画を追加します。
   - keyword-map にない新規候補を使う場合のみ、ラッコキーワード `search-volume-history` で検索数・難易度を取得します。
   - 3領域（営業改善／WEB改善／AI活用）が偏らないよう、4週間で各領域1本以上を目安に配置します。
4. **今週着手する記事の構成案（ステップ5の前半）**
   - 今後2週間以内に公開予定で状態が「企画中」の記事（最大2本）について、ラッコキーワード `headline` `co-occurrence` `question-search` で上位ページを調べ、構成案を `growcross/content/YYYY-MM-DD_<slug>.md` に作成します。状態を「構成案承認待ち」に更新します。
   - 「構成案承認」と記録された記事があれば本文・画像指示書・入稿パッケージまで作成し、状態を「入稿パッケージ承認待ち」に更新します。
5. **週次企画書の作成**: `growcross/content/weekly-plan_YYYY-MM-DD.md`
   ```markdown
   # 週次コンテンツ企画（YYYY-MM-DD週）
   ## 1. 今週のサマリー（3行）
   ## 2. 今週の制作予定（ID｜公開予定日｜領域｜主KW｜状態｜次の作業）
   ## 3. 先週からの変化・停滞案件
   ## 4. 新たに追加した企画と追加理由（検索数・難易度は出典と取得日つき）
   ## 5. 承認依頼（構成案・入稿パッケージ）
   ## 6. 不足データ
   ```

## 保存と共有
- 作業ブランチ `growx-ops` を最新化して作業し、コミットして `growx-ops` にpushします。
- 最後に、上記の企画書の要点（サマリー・承認依頼・不足データ）を報告します。

## やらないこと
- WordPressへの登録・公開、既存記事の書き換え
- 構成案の承認前に本文を書くこと
