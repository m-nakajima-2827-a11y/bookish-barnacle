# トップページをGoogleに登録する手順（グロウクロス）

作成日: 2026-11-20
背景: 社名「グロウクロス」の検索で、表示されるのは問い合わせページ（9位）だけで、トップページは30位以内に出ていない（ラッコキーワード 検索順位チェック、2026-11-18）。
注意: 登録のリクエストをしても、Googleが登録するかどうか・いつ登録するかはGoogleが判断します（数日〜数週間かかることがあります）。

## 1. WordPressの設定確認（3分）
1. WordPress管理画面 → 設定 → 表示設定
2. 「検索エンジンでの表示」の **「検索エンジンがサイトをインデックスしないようにする」にチェックが入っていないこと** を確認（入っていれば外して保存）
3. SEOプラグイン（Yoast SEO、All in One SEO、SEOPress、Rank Math など）を使っている場合は、トップページの編集画面で「検索結果に表示しない（noindex）」になっていないことを確認

## 2. サイトマップの送信（3分）
1. ブラウザで `https://www.grow-cross.com/sitemap.xml` を開き、ページ一覧が表示されることを確認（表示されない場合は `https://www.grow-cross.com/wp-sitemap.xml` も試す）
2. サーチコンソール → 左メニュー「サイトマップ」 → 表示されたサイトマップのURLを入力して「送信」
3. ステータスが「成功しました」になることを確認

## 3. トップページの登録リクエスト（3分）
1. サーチコンソール上部の検索窓に `https://www.grow-cross.com/` を入力して Enter（URL検査）
2. 右上の「公開 URL をテスト」を押し、「URL は Google に登録できます」と表示されることを確認
   - 「登録できません」と出た場合は、表示された理由（noindex、robots.txt、リダイレクト等）を控えて、作業を止める
3. 「インデックス登録をリクエスト」を押す
4. `https://grow-cross.com/`（www なし）も同じように URL検査し、www ありのURLへ転送されているかを確認（転送されていない場合はその旨を控える）

## 4. 結果の確認（1〜2週間後）
- サーチコンソールで `https://www.grow-cross.com/` を再度 URL検査し、「URL は Google に登録されています」になったか
- 「検索パフォーマンス」でクエリ「グロウクロス」の表示回数・平均掲載順位
- 社名検索の順位は、`growcross-reporting` でラッコキーワードの順位チェックを再実行して確認

## 5. 控えて共有してほしいこと
| 項目 | 内容 |

| サイトマップのURLと送信結果 | |
| 公開URLのテスト結果（www あり） | 登録できる／できない（理由） |
| www なしのURLの状態 | www ありへ転送される／されない |
| リクエストした日 | |
