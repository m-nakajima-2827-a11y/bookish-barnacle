# ChatGPTへの作業指示：トップページをGoogleに登録する

作成日: 2026-11-21
使い方: 下の「指示文」をそのままChatGPTに貼り付けてください。
- ChatGPTがブラウザを操作できる場合（エージェント機能）: ログインはご担当者が行い、その後の操作をChatGPTに任せます。**パスワードはChatGPTに貼り付けないでください。**
- ChatGPTがブラウザを操作できない場合: ChatGPTに手順を1つずつ案内させ、ご担当者が画面で操作します。

---

## 指示文（ここから下をコピー）

あなたはWebサイトのSEO作業担当です。グロウクロスのWebサイト（https://www.grow-cross.com、WordPress）のトップページを、Googleに登録（インデックス登録）してもらうための作業を行います。次の条件と手順に正確に従ってください。判断に迷う点、想定と違う表示が出た点があれば、作業を止めて質問してください。

### 1. 背景と目的
- 社名「グロウクロス」でGoogle検索すると、表示されるのは問い合わせページ（9位）だけで、トップページは30位以内に出ていません（2026-11-18の順位調査）。
- 目的は、トップページがGoogleに登録できる状態かを確認し、サイトマップの送信とトップページの登録リクエストを行うことです。
- 登録するかどうか・いつ登録するかはGoogleが判断します。今回の作業は「リクエストまで」です。

### 2. 使うもの
| 項目 | 内容 |
|---|---|
| WordPress管理画面 | `https://www.grow-cross.com/wp-admin/`（ログインはご担当者が行います） |
| Google サーチコンソール | `https://search.google.com/search-console`（grow-cross.com のプロパティ。ログインはご担当者が行います） |
| 対象URL | `https://www.grow-cross.com/`（www あり）と `https://grow-cross.com/`（www なし） |

### 3. 手順

**手順1：WordPressの「検索エンジンでの表示」を確認する**
1. WordPress管理画面 → 「設定」 → 「表示設定」を開く
2. 「検索エンジンでの表示」の「検索エンジンがサイトをインデックスしないようにする」の状態を確認する
3. チェックが **入っていない** → そのまま次へ（何も変更しない）
4. チェックが **入っている** → 作業を止めて、ご担当者に「チェックが入っています。外してよいですか」と確認する。許可が出たら外して「変更を保存」する

**手順2：SEOプラグインのトップページ設定を確認する**
1. 管理画面の「プラグイン」で、SEOプラグイン（Yoast SEO、All in One SEO、SEOPress、Rank Math など）が有効かを確認する
2. 有効な場合は、トップページ（「設定」→「表示設定」の「ホームページの表示」で指定されている固定ページ、または投稿一覧）のSEO設定で、「検索結果に表示しない（noindex）」になっていないかを確認する
3. noindex になっていた場合は、作業を止めてご担当者に確認する（勝手に変更しない）

**手順3：サイトマップを確認する**
1. ブラウザで `https://www.grow-cross.com/sitemap.xml` を開く
2. ページの一覧（またはサイトマップの一覧）が表示されれば、このURLを使う
3. 表示されない（404など）場合は `https://www.grow-cross.com/wp-sitemap.xml` を開き、表示されればこちらを使う
4. SEOプラグインを使っている場合は `https://www.grow-cross.com/sitemap_index.xml` も確認する
5. どれも表示されない場合は、作業を止めて報告する

**手順4：サーチコンソールでサイトマップを送信する**
1. サーチコンソールで grow-cross.com のプロパティを選ぶ
2. 左メニュー「サイトマップ」を開く
3. すでに同じサイトマップが「成功しました」で登録されていれば、送信は不要（状態を控える）
4. 未登録の場合は、手順3で確認したサイトマップのURLを入力して「送信」する
5. ステータス（「成功しました」「取得できませんでした」など）を控える

**手順5：トップページ（www あり）を検査し、登録をリクエストする**
1. サーチコンソール上部の検索窓に `https://www.grow-cross.com/` を入力して Enter
2. 表示された結果を控える：
   - 見出し（「URL は Google に登録されています」または「URL が Google に登録されていません」）
   - 「ページのインデックス登録」の状態と理由
   - 詳細を開いたときの「ユーザーが指定した正規 URL」と「Google が選択した正規 URL」
3. 右上の「公開 URL をテスト」を押し、結果を控える
4. 「URL は Google に登録できます」と出た場合のみ、「インデックス登録をリクエスト」を押し、完了メッセージを控える
5. 「登録できません」と出た場合は、リクエストせずに理由（noindex、robots.txt によるブロック、リダイレクト等）を控えて報告する

**手順6：www なしのURLを確認する**
1. サーチコンソールの検索窓に `https://grow-cross.com/` を入力して Enter
2. 結果を控える（特に「ページにリダイレクトがあります」と出るか、どこに転送されるか）
3. ブラウザでも `https://grow-cross.com/` を開き、`https://www.grow-cross.com/` に自動で移動するかを確認する
4. **このURLには登録リクエストをしない**（www ありを正式なURLとするため）

### 4. してはいけないこと
- ご担当者の許可なく、WordPressの設定・SEOプラグインの設定・テーマ・プラグイン・ページの内容を変更しない（手順1で許可を得た変更のみ可）
- `robots.txt`、`.htaccess`、リダイレクトの設定を変更しない（問題を見つけたら報告のみ）
- サーチコンソールのプロパティの削除・追加、ユーザー権限の変更をしない
- 「削除」ツール（URLの一時削除）を使わない
- 同じURLに何度も登録リクエストを送らない（1回でよい）
- ログイン情報（パスワード等）を入力・保存・表示しない（ログインはご担当者が行う）

### 5. 報告の形式
作業後、次の表を埋めて報告してください。

| 項目 | 結果 |
|---|---|
| 手順1：「検索エンジンがサイトをインデックスしないようにする」 | チェックなし／チェックあり（外した・外していない） |
| 手順2：SEOプラグイン名とトップページの noindex | プラグイン名／noindex なし・あり |
| 手順3：使ったサイトマップのURL | |
| 手順4：サイトマップの送信結果 | 成功しました／取得できませんでした／その他 |
| 手順5：URL検査の見出し（www あり） | |
| 手順5：「ページのインデックス登録」の状態と理由 | |
| 手順5：ユーザーが指定した正規 URL／Google が選択した正規 URL | |
| 手順5：公開 URL のテスト結果 | 登録できます／登録できません（理由） |
| 手順5：登録リクエスト | 実施した（日時）／実施していない（理由） |
| 手順6：www なしのURL | www ありへ転送される／されない／その他 |
| その他、気づいた点 | |
