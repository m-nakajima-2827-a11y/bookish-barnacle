# ChatGPTへの作業指示：予約完了ページの「トップページへ戻る」ボタン

作成日: 2026-11-20
使い方: 下の「指示文」をそのままChatGPTに貼り付けてください。ChatGPTがWordPressを直接操作できない場合は、手順をChatGPTに案内させ、ご担当者が画面で操作します。

---

## 指示文（ここから下をコピー）

あなたはWordPressの作業担当です。グロウクロス（https://www.grow-cross.com）のWordPressで、予約完了ページに「トップページへ戻る」ボタンを設置します。次の条件と手順に正確に従ってください。判断に迷う点があれば、作業を止めて質問してください。

### 1. 作業の目的
相談予約を完了した人が、迷わずサイトのトップページに戻れるようにします。

### 2. 対象ページ
| 項目 | 内容 |
|---|---|
| ページ | 固定ページ「無料相談のご予約ありがとうございます」 |
| URL | `https://www.grow-cross.com/consultation/thanks/` |
| 親ページ | 「無料相談のご予約」（`/consultation/`） |

**このページがまだない場合**は、先に次の内容で固定ページを作成してください（スラッグ `thanks`、親ページ「無料相談のご予約」）。

> **見出し（ページタイトル）**: 無料相談のご予約ありがとうございます
>
> ご予約を承りました。ご登録のメールアドレスに、予約内容とGoogle Meetの参加用URLをお送りしています。前日にもリマインダーをお送りします。
>
> **当日までにご用意いただくと、相談がスムーズです（任意）**
> - 現在の営業の進め方（担当者数、主な取引先、新規開拓の方法など）
> - AIで効率化したい業務があれば、その内容
>
> メールが届かない場合は、迷惑メールフォルダをご確認のうえ、お問い合わせフォーム（https://www.grow-cross.com/inquiry/ へのリンク）からご連絡ください。

### 3. ボタンの仕様
| 項目 | 値 |
|---|---|
| 設置位置 | 本文の最後（「メールが届かない場合は…」の段落の下） |
| ボタンの文字 | トップページへ戻る |
| リンク先 | `https://www.grow-cross.com/` |
| 開き方 | 同じタブで開く（新しいタブにしない） |
| 配置 | 中央揃え |
| 余白 | 上に 32px 程度 |
| 色 | サイトの既存ボタン（ヘッダーの「無料相談を予約」ボタンなど）と同じ色・形。既存ボタンがない場合はテーマの標準ボタンスタイルのまま |
| スマホ | 画面幅に収まり、指で押しやすい大きさ（高さ 44px 以上が目安） |

### 4. 手順（使っている編集画面に合わせて実施）
まず、このサイトの固定ページの編集画面が次のどれかを確認してください。
- **A. ブロックエディター（Gutenberg）**
- **B. Elementor などのページビルダー**
- **C. クラシックエディター**

**A. ブロックエディターの場合**
1. 管理画面 → 固定ページ → 「無料相談のご予約ありがとうございます」を編集
2. 本文の最後の段落の下で「＋」→「ボタン」ブロックを追加
3. ボタンに「トップページへ戻る」と入力
4. リンクに `https://www.grow-cross.com/` を設定（「新しいタブで開く」はオフ）
5. 「ボタン」ブロック（親）の配置を「中央揃え」にする
6. 右側の設定でスタイルを既存ボタンに合わせる。上の余白は「スペーサー」ブロック（32px）か、ブロックの余白設定で調整
7. 「更新」で保存

**B. Elementor の場合**
1. ページを Elementor で編集
2. 本文の最後に「ボタン」ウィジェットを追加
3. テキスト「トップページへ戻る」、リンク `https://www.grow-cross.com/`、配置は中央、スタイルは既存ボタンに合わせる
4. 「更新」で保存

**C. クラシックエディター（またはカスタムHTMLしか使えない場合）**
本文の最後に、テキスト（HTML）モードで次を追加してください。

```html
<p style="text-align:center; margin-top:32px;">
  <a href="https://www.grow-cross.com/" class="wp-element-button"
     style="display:inline-block; min-height:44px; padding:12px 32px; text-decoration:none;">
    トップページへ戻る
  </a>
</p>
```
`class="wp-element-button"` がテーマで効かない場合は、テーマの既存ボタンのクラス名に置き換えてください。

### 5. 変更してはいけないこと
- このページの **検索除外（noindex）設定** を外さない（SEOプラグインの「検索結果に表示しない」等の設定）
- このページを **メニューやサイトマップに追加しない**
- ページの **URL（`/consultation/thanks/`）を変えない**（予約ツールJicooの完了後の移動先と、GA4の計測に使っているため）
- 他のページ、テーマの設定、プラグインは変更しない
- GA4やタグマネージャーの設定には触れない

### 6. 完了の確認
作業後に次を確認し、結果を一覧で報告してください。
1. PCとスマホで `https://www.grow-cross.com/consultation/thanks/` を開き、本文の最後にボタンが中央に表示される
2. ボタンを押すと、同じタブでトップページ（`https://www.grow-cross.com/`）が開く
3. ボタンの色・形が、サイトの他のボタンと揃っている
4. ページの検索除外（noindex）が設定されたままになっている（ページのHTMLに `<meta name="robots" content="noindex` が含まれる）
5. 変更したのはこのページだけである

### 7. 報告の形式
- 使った編集画面（A／B／C）
- 実施した手順
- 確認結果（1〜5のそれぞれ OK／NG）
- うまくいかなかった点と、その理由

## 補足（ご担当者向け）
- ChatGPTがWordPressを操作する場合も、ログイン情報はChatGPTに貼り付けず、ご自身で操作するか、権限を絞ったユーザーを用意してください。
- 作業後は、確認項目4（noindex）をご自身でも確認してください。外れると、完了ページが検索結果に出てしまい、予約していない人がアクセスして予約数の計測が狂う原因になります。
