# 相談予約ツール 導入計画（グロウクロス）

作成日: 2026-11-17（同日、カレンダー・会議ツール・相談の条件・CMSを反映）
目的: 相談予約（最優先のCV）を、問い合わせフォームでの日程のやり取りから、**日時を選んでその場で予約が完了する形** に変え、予約数と予約完了率を上げる。

## 前提（ご担当者回答）
| 項目 | 内容 |
|---|---|
| カレンダー | Googleカレンダー |
| Web会議 | Google Meet |
| 初回相談 | 30分・無料 |
| 担当者 | 1名 |
| サイト | WordPress |
| 既存の問い合わせフォーム | `https://www.grow-cross.com/inquiry/`。種別に「サービスについて／お見積りについて／打ち合わせ・ご相談／その他」がある（検索結果の説明文より） |

## 1. 現状と課題
| 項目 | 現状（事実） | 課題（仮説） |
|---|---|---|
| 相談の受け方 | 問い合わせフォームで受付 | 送信後に日程調整のメール往復が発生し、その間に検討が止まる・他社に流れる可能性 |
| 計測 | GA4・サーチコンソールは設定済み | 「相談予約」と「その他の問い合わせ」を分けて計測できているかは要確認 |
| 初回接触 | 要確認 | 予約確定までの時間が長いほど、商談化率が下がる傾向がある（一般論） |

## 2. 予約ツールに求める要件
| 区分 | 要件 | 理由 |
|---|---|---|
| 必須 | Googleカレンダー（または使用中のカレンダー）と連携し、空き時間だけを表示 | ダブルブッキング防止 |
| 必須 | オンライン面談URL（Google Meet / Zoom）の自動発行 | 全国対応のため |
| 必須 | 予約時の質問項目（会社名・業種・従業員数・相談したいこと） | 事前準備と、業種別の育成・分析に使う |
| 必須 | 確認メール・前日リマインダーの自動送信 | 当日のキャンセル・無断欠席を防ぐ |
| 必須 | **予約完了後に自社サイトのページへリダイレクトできる**、またはGA4へ完了イベントを送れる | GA4で予約完了をキーイベントとして計測するため |
| 必須 | 自社サイトのページに埋め込める | 相談予約ページから離脱させないため |
| 推奨 | 予約受付の条件設定（受付時間、前後の空き時間、1日の上限、何時間前まで予約可） | 営業時間内で無理なく対応するため |
| 推奨 | 予約時のSlack・メール通知、Webhook | 担当者がすぐ準備できるように。MAへの連携にも使う |
| 推奨 | 複数担当者への自動割り当て | 担当者が増えた場合に備えて |

## 3. 候補ツール（2026年11月時点の公開情報。料金・機能は契約前に公式サイトで要確認）
| ツール | 特徴（公開情報） | 料金の目安（公開情報） | 確認が必要な点 |
|---|---|---|---|
| TimeRex | 国産。予約受付型・候補提案型に対応。Webサイトへの埋め込みや広告計測など、マーケティング向けの機能があると紹介されている | 無料プランあり（1対1の調整）。有料は1人あたり月750円〜900円程度と記事によって差あり | 予約完了後のリダイレクト・GA4計測の可否、有料プランの機能範囲 |
| Jicoo | 国産。Google・Outlook・iCloudのカレンダー、Web会議ツールと連携。無料プランは1対1で回数制限なしとの記載あり | 無料プランあり。複数人の自動割り当ては上位プラン | 予約完了後のリダイレクト・GA4計測の可否 |
| Googleカレンダーの予約スケジュール | 追加ツール不要。個人アカウントは予約ページ1つ。リマインダーメール等は有料のWorkspace/Google Oneプランで利用可 | 既存のGoogle契約による | 予約完了後のリダイレクト・GA4計測の可否、質問項目の柔軟さ |
| Calendly | 海外で広く使われる。公式の日本語対応がない点が指摘されている | 有料は月8〜10ドル程度との記載 | 日本語での利用感（顧客側の画面） |

### 推奨（仮説）
Googleカレンダー・Google Meet・担当1名という条件では、どの候補もカレンダー連携と面談URLの自動発行に対応できる見込みです。決め手は次の2点です。

| 判断軸 | TimeRex / Jicoo | Googleカレンダーの予約スケジュール |
|---|---|---|
| 予約完了のGA4計測 | 各社ヘルプで要確認（完了後のリダイレクト先指定、またはGA4連携） | 要確認 |
| 前日リマインダー | 要確認（プランによる） | 有料のWorkspace / Google Oneプランで利用可（公開情報） |
| 質問項目・Webhook通知 | 要確認 | 要確認 |
| 追加の契約 | 無料プランから開始可 | 既存のGoogle契約による |

第一候補は、国産で日本語の画面が自然な **TimeRex** または **Jicoo** です（無料プランで試用）。すでに有料のGoogle Workspaceを契約していて、Googleの予約スケジュールで完了計測ができる場合は、ツールを増やさずに済むGoogleを優先します。**予約完了をGA4で計測できること** を必須条件として、公式ヘルプで確認してから決定します。

> 予約完了の計測方法が用意されていないツールは、相談予約の成果を測れなくなるため選びません。

## 4. 計測設計（GA4）
| 計測するもの | 方法 | GA4での扱い |
|---|---|---|
| 相談予約ページの表示 | ページビュー（`/consultation/` など） | 通常のイベント |
| 予約完了 | ①完了後に自社の完了ページ（例: `/consultation/thanks/`）へリダイレクトし、その表示を計測 ②ツールがGA4・タグマネージャーにイベントを送れる場合はそれを使う | キーイベント `consultation_booked` |
| 問い合わせ送信 | 既存フォームの送信完了 | キーイベント `inquiry_submit`（相談予約とは分ける） |
| 流入元 | 予約ページへのリンクはUTM付き（`build_utm_tracking_url` で発行） | 参照元／メディア別の予約数 |

- ①の方法をとる場合、完了ページは検索結果に出ないよう `noindex` にします。
- 予約ツールの管理画面の予約数と、GA4のキーイベント数を月1回照合し、計測漏れがないかを確認します。

## 5. 予約フローと運用ルール（案）
```
相談予約ページ（自社サイト）
  └ 予約カレンダー（埋め込み）で日時を選択
      └ 質問項目に回答（会社名・氏名・メール・業種・従業員数・相談したいこと・配信同意）
          └ 予約完了 → 完了ページ（GA4キーイベント）
              ├ 自動: 確認メール（面談URL）・前日リマインダー
              ├ 自動: 担当者へ通知（Slack/メール）
              └ 自動: MAに登録（Webhook → 相談予約フォームとして取り込み → ホットリードとして営業引き渡し）
```

| 設定項目 | 初期値（案・仮置き） |
|---|---|
| 面談時間 | 30分・無料（確定） |
| 面談方法 | Google Meet（予約確定時に会議URLを自動発行） |
| 受付時間 | 平日 10:00〜17:00（案） |
| 前後の空き時間 | 15分（案。担当1名のため、準備と記録の時間を確保） |
| 予約の締め切り | 前営業日まで（案。当日予約は不可） |
| 1日の上限 | 3件（案。担当1名の通常業務との両立のため） |
| 受付期間 | 3週間先まで（案） |
| 不在時 | Googleカレンダーに予定（外出・休暇）を入れれば、その時間は予約不可になる |

## 6. サイト側の変更
| 変更 | 内容 |
|---|---|
| 相談予約ページの新設 | 相談で分かること、対象、所要時間、オンライン対応、費用、担当者紹介、予約カレンダー |
| 導線 | 全ページのヘッダーに「無料相談を予約」、各サービス・業種ページの末尾にも設置 |
| 問い合わせフォーム | 残す（予約以外の問い合わせ用）。フォーム上部に「日程を決めて相談したい方はこちら」と予約ページへのリンク |
| SNS | Instagram・Facebookのプロフィールのリンクを相談予約ページ（UTM付き）に |

## 6-2. WordPressでの実装手順
| # | 作業 | 内容 |
|---|---|---|
| 1 | 予約ツールの設定 | Googleカレンダー連携、Google Meet連携、上表の受付条件、質問項目（会社名・氏名・メール・業種・従業員数・相談したいこと・メール配信の同意）、確認メール・リマインダー |
| 2 | 相談予約ページ | 固定ページ「無料相談のご予約」（URL案: `/consultation/`）を作成。相談で分かること・対象・30分無料・オンライン（Google Meet）・担当者紹介を書き、予約ツールの埋め込みコードを「カスタムHTML」ブロックで貼り付け |
| 3 | 予約完了ページ | 固定ページ（URL案: `/consultation/thanks/`）を作成し、予約ツールの「完了後のリダイレクト先」に設定。SEOプラグイン等で `noindex` にする |
| 4 | GA4のキーイベント | GA4の管理画面 → イベント → 「イベントを作成」で、`page_view` かつページURLに `/consultation/thanks/` を含む条件の `consultation_booked` を作成し、キーイベントに設定 |
| 5 | 導線 | ヘッダーのメニューに「無料相談を予約」ボタン、各サービスページ末尾にボタン。問い合わせフォーム（`/inquiry/`）の上部に「日程を決めてご相談の方はこちら」と予約ページへのリンク |
| 6 | 既存フォームの整理 | 問い合わせ種別「打ち合わせ・ご相談」を選ぶ人を予約ページへ誘導する文言を追加（フォームは残す） |
| 7 | テスト | PC・スマホで予約 → Googleカレンダーに予定とMeet URLが入る、確認メールが届く、完了ページが表示される、GA4の「リアルタイム」でキーイベントが記録される、を確認してからテスト予約を削除 |

> 完了後のリダイレクト先を指定できないツールの場合は、手順3・4の代わりに、ツールが用意するGA4／タグマネージャー連携の方法を使います（ツール決定時に確定）。

## 7. スケジュール（目安）
| 週 | 作業 | 担当（想定） |
|---|---|---|
| 1週目 | 候補ツールの公式ヘルプで計測可否を確認し、無料プランで試用・ツール決定 | Web担当 |
| 1〜2週目 | 予約ページ・完了ページの作成、質問項目・通知・リマインダーの設定 | Web担当・コンサル担当 |
| 2週目 | GA4キーイベント設定、テスト予約（PC・スマホ）、管理画面とGA4の数の照合 | Web担当 |
| 3週目 | 公開、ヘッダー・各ページ・SNSプロフィールの導線切り替え | Web担当・SNS担当 |
| 公開後4週 | 予約数・予約完了率の確認、質問項目や文言の見直し | マーケ責任者 |

## 8. KPI
| 指標 | 計算 | 目標 |
|---|---|---|
| 相談予約数（月） | GA4 `consultation_booked` | 要設定（現状の相談件数を把握してから設定） |
| 予約完了率 | 予約完了 ÷ 相談予約ページの表示 | 要設定（公開後4週の実績から設定） |
| 無断欠席・当日キャンセル率 | 予約ツールの管理画面 | 要設定 |
| 相談からの商談化率 | CRM・営業記録 | 要設定 |
