# Jicoo 相談予約 設定チェックリスト（グロウクロス）

作成日: 2026-11-18
前提: Googleカレンダー・Google Meet（Google Workspace、grow-cross.com）、初回30分・無料、担当1名、WordPress
関連: `booking-tool-plan.md`（全体計画）、`../content/consultation-page-draft.md`（ページ文章案）

> Jicooの画面名・設定項目名は、公開情報（2022年のアップデート案内など）と一般的な予約ツールの構成からの想定です。実際の画面と異なる場合は、Jicooのヘルプに従ってください。料金・プランは契約前に公式サイトで確認します。

## 0. 契約前の確認（所要: 30分）
- [ ] 予約完了後に任意のURLへ移動する設定が、契約予定のプランで使える
- [ ] サイトに埋め込んだ予約ページからでも、完了後の移動が働く
- [ ] Googleカレンダー連携、Google Meetの自動発行、質問項目、確認メール、リマインダーが同じプランで使える
- [ ] 月額料金・支払い方法・解約条件

## 1. アカウントと連携（所要: 15分）
- [ ] 担当者の Google Workspace アカウント（@grow-cross.com）でJicooに登録
- [ ] Googleカレンダーを連携（空き時間の判定に使うカレンダーを選択。私用の予定も入るカレンダーがあれば、それも「予定あり」の判定に含める）
- [ ] Google Meet を会議の場所として設定（予約確定時にURLを自動発行）

## 2. 予約ページの設定（所要: 30分）
| 設定 | 値 |
|---|---|
| 予約ページ名 | 無料相談（30分・オンライン） |
| 所要時間 | 30分 |
| 場所 | Google Meet |
| 受付時間 | 平日 10:00〜17:00 |
| 前後の空き時間 | 前後15分 |
| 予約の締め切り | 前営業日まで（当日不可） |
| 1日の上限 | 3件 |
| 受付期間 | 3週間先まで |
| 予約完了後の移動先 | `https://www.grow-cross.com/consultation/thanks/` |
| 移動時のパラメータ | 付ける場合も、氏名・メールアドレスは含めない |

### 質問項目
| 項目 | 形式 | 必須 |
|---|---|---|
| 会社名 | 1行テキスト | 必須 |
| お名前 | 1行テキスト | 必須 |
| メールアドレス | メール | 必須 |
| 業種 | 選択（製造業／サービス業／不動産／介護施設の運営／その他） | 必須 |
| 従業員数 | 選択（1〜9名／10〜49名／50〜299名／300名以上） | 必須 |
| ご相談したいこと | 選択（営業／AI活用／両方／その他） | 必須 |
| ご相談内容 | 複数行テキスト | 任意 |
| お役立ち情報のメールを受け取る | チェックボックス | 任意 |

### 通知
- [ ] 予約確定メール（顧客）: Google MeetのURL、日時、変更・キャンセル方法
- [ ] リマインダー（顧客）: 前日
- [ ] 担当者への通知: 予約・変更・キャンセル時（メール。Slackを使っている場合はSlack連携の有無を確認）

## 3. WordPress（所要: 1〜2時間）
- [ ] 固定ページ `/consultation/` を作成（文章は `consultation-page-draft.md` のA）。Jicooの埋め込みコードを「カスタムHTML」ブロックで貼り付け
- [ ] 固定ページ `/consultation/thanks/` を作成（文章は同B）。`noindex` に設定し、メニュー・サイトマップから外す
- [ ] ヘッダーのメニューに「無料相談を予約」ボタン（リンク先 `/consultation/`）
- [ ] 各サービスページの末尾に予約ボタン
- [ ] 問い合わせフォーム `/inquiry/` の上部に予約ページへの案内文（同C）

## 4. GA4（所要: 15分）
- [ ] 管理 → イベント → 「イベントを作成」: 名前 `consultation_booked`、条件 `event_name = page_view` かつ `page_location` に `/consultation/thanks/` を含む
- [ ] `consultation_booked` をキーイベントに設定
- [ ] 既存の問い合わせ送信が `inquiry_submit` などの名前でキーイベントになっているか確認（相談予約と分けて数えるため）

## 5. テスト（所要: 30分）
- [ ] PCで予約 → 完了ページが表示される
- [ ] スマホで予約 → 完了ページが表示される
- [ ] Googleカレンダーに予定が入り、Google MeetのURLが付いている
- [ ] 確認メールが届く（迷惑メールに入らないか）
- [ ] GA4の「リアルタイム」で `consultation_booked` が記録される
- [ ] UTM付きのURL（例: Instagramのプロフィールリンク）から予約し、GA4で参照元が `instagram` になる
- [ ] テスト予約をキャンセル・削除し、キャンセル通知が届くことも確認

## 6. 公開と周知
- [ ] Instagram・Facebookのプロフィールのリンクを、UTM付きの予約ページURLに変更（`build_utm_tracking_url` で発行。例: `utm_source=instagram&utm_medium=social&utm_campaign=consultation&utm_content=profile_link`）
- [ ] 公開から1週間後: Jicooの予約数とGA4の `consultation_booked` の数を照合
- [ ] 公開から4週間後: 予約完了率（完了 ÷ 予約ページの表示）を確認し、ページの文言や質問項目を見直す（`growcross-reporting`）
