# 自社開発MA 機能仕様書（SATORIの機能構成に準拠）

## 1. 位置づけ

- MA（マーケティングオートメーション）は外部のMAツールを使わず、本リポジトリのオリジナルSkillとして実装しています（`src/dm_agent/ma/`, `src/dm_agent/skills/ma.py`）。
- 機能の構成と考え方は、国産MA「SATORI」の**公開されている機能紹介・ヘルプ記事**に準拠しています。
- 本実装はSATORIのAPIや画面との互換を保証するものではありません。
- SATORIで仕様が公開されていない部分は、本実装で独自に定めています。該当箇所は表の「本実装での追加・仮定」に明記しました。

## 2. 機能対応表

| SATORIの機能（公開情報） | 本実装のツール／action | 実装内容 | 本実装での追加・仮定 |
|---|---|---|---|
| 計測タグ・匿名客の行動記録（アンノウンマーケティング） | `ma_track_activity` | CookieIDごとに匿名客のWebアクセス・UTMを記録し、スコア・セグメントに反映 | Cookieの発行・タグ配信（tag.js）は本番時に実装 |
| カスタマー管理（匿名客・実名客） | `ma_manage_customer`（get / search / update_attributes） | 匿名客と実名客を同じ「カスタマー」として管理 | 連絡先は出力・ログで常にマスク |
| 実名化・名寄せ | `ma_manage_form`（submit） | フォーム送信時にメールアドレスで名寄せし、送信元Cookieの匿名履歴を引き継ぐ | 既に別の実名客に紐付くCookie（共用PC）は統合しない |
| タグ | `ma_manage_customer`（add_tag / remove_tag）、フォーム送信時タグ、シナリオのタグ付与 | タグ付与を起点とするシナリオ・個別スコアに対応 | |
| セグメント | `ma_manage_segment` | ページ閲覧（URL・回数・期間）、UTM、メール反応、フォーム送信、タグ、スコア、属性、匿名/実名、プッシュ許諾、配信同意を all/any/not で組み合わせ。新たに該当した時点でシナリオ起動 | リードステージ条件（CRM連動）を追加。作成時点の既存該当者ではシナリオを起動しない |
| スコアリング／スコア定義（共通設定） | `ma_configure_scoring`（set_common） | 既定値: Webアクセス+5、メール内リンククリック+10、メール開封+1、メール配信拒否−30 | フォーム送信・ポップアップクリック・プッシュクリックの共通値（既定0）を追加 |
| スコア定義（個別設定） | `ma_configure_scoring`（add_rule / remove_rule） | URLフィルタ・パラメータフィルタ、タグ付与時、セグメント該当時の加減点。±100,000以内の整数 | 特定フォーム送信の個別設定を追加。個別設定に該当したWebアクセスは共通設定を加算しない（仮定） |
| シナリオ（トリガー → ステップメール・タグ追加・社内通知） | `ma_manage_scenario` | トリガー: セグメント該当 / フォーム送信 / タグ付与。ステップ: N日後のメール、タグ付与・削除、通知 | 離脱条件（リードステージ・タグ・セグメント）、閲覧済み資料のステップスキップ、下書き→開始の運用 |
| シナリオ通知（通知先拡張・Webhook） | シナリオの `notify`、フォームの `notify` | Webhook（Slack等）、CRMタスク | 通知内容に連絡先は含めない |
| メール配信 | `ma_send_email` | 個別・セグメント一斉・予約・テスト、差し込み、クリック・開封計測、配信停止リンク、送信者情報 | 同意・頻度上限・同一資料の再送禁止・営業時間のガードレール |
| フォーム | `ma_manage_form`（create / submit / list） | 項目定義、必須チェック、同意チェック、自動返信、通知、送信時タグ | リード（資料DL・セミナー申込・問い合わせ）への自動連携、会社ドメインでの企業ID付与 |
| ランディングページ | `ma_create_landing_page` | フォーム・計測タグ入りのレスポンシブなLPのHTMLを生成 | テーマカラー指定、入力値のHTMLエスケープ |
| ポップアップ | `ma_manage_popup` | フォーム型・バナー型。表示条件: セグメント、URL、匿名/実名、頻度、最大回数、表示秒数、期間 | クリック後の非表示（既定） |
| Webプッシュ通知 | `ma_send_web_push` | 許諾した訪問者（匿名客を含む）へのセグメント配信・予約 | 7日3回の頻度上限、営業時間内配信 |
| レポート・分析 | `ma_get_report` | 概要（実名化率・スコア分布）、メール、ポップアップ、フォーム、プッシュ、シナリオ、セグメント | 商談・受注までの分析は `analyze_marketing_funnel` と連携 |
| 外部連携（CRM・チャット） | Webhook、CRMタスク、`sync_lead_activity` 連携 | 実名客の行動・フォーム送信をリード管理・スコアリング・営業引き渡しへ自動連携 | Salesforce等の双方向同期は本番時に実装 |

## 3. データとプライバシー

| 項目 | 方針 |
|---|---|
| 連絡先（メールアドレス・氏名・電話番号） | MAのカスタマー情報（`contact`）にのみ保存します。ツール出力・監査ログ・Webhook・リード管理（LeadStore）にはマスク済みの値だけが出ます（例: `y***@sample-seiki.example`） |
| メール配信の同意 | フォームの同意チェック、または取得経路を記録した手動登録（`record_opt_in`）のみで成立します。配信停止したカスタマーを手動で同意に戻すことはできません |
| 自動返信 | 請求された資料の送付は取引メールとして、同意・頻度上限の対象外です（**運用前に法務確認**） |
| 外部送信 | 広告媒体にはハッシュ化したIDのみを送ります。Webhookの本文には連絡先を含めません |

## 4. 既定の設定（`config/clients/sample_sales_consulting.json` の `ma`）

| 種別 | ID | 内容 |
|---|---|---|
| フォーム | F-WP-MFG / F-WP-IT | 業界別の資料DL（自動返信で資料送付、マーケ用チャンネルへ通知） |
| フォーム | F-SEMINAR / F-CONTACT | セミナー申込／問い合わせ・無料診断（問い合わせは営業用チャンネルへ即時通知） |
| セグメント | SEG-ANON-LP-REVISIT | 匿名でLPを14日以内に2回以上閲覧 → 資料DLポップアップの対象 |
| セグメント | SEG-PRICE-30D / SEG-SCORE-100 / SEG-MFG-OPTIN / SEG-IT-OPTIN / SEG-PUSH | 料金ページ閲覧、スコア100以上の実名客、業種別の配信可、プッシュ許諾者 |
| 個別スコア | R-PRICE 他 | 料金ページ+20、事例+10、問い合わせ+50、セミナー申込+30、資料DL+20 |
| ポップアップ | P-MFG-DL / P-SEMINAR | LP再訪の匿名客に資料DLフォーム／料金ページ閲覧者にセミナー案内 |
| シナリオ | SC-SCORE-ALERT / SC-SEMINAR-FOLLOW / nurture_* | スコア100到達で営業通知／セミナー申込翌日に事例案内／業界別育成 |

点数・条件・頻度はすべて初期仮説です。運用データを見て調整してください。
